# CSV 스키마 메모

CSV는 조사 사고 1건당 1행입니다. 앞의 7개 워크플로 메타데이터 뒤에 요청된 조사 칼럼이 선언 순서대로 이어집니다.

## 워크플로 메타데이터

| 칼럼 | 내용 |
| --- | --- |
| `case_id` | `SAMSUNG-001` 등 `기관-번호` 형식의 표시 식별자 |
| `workflow_status` | `draft` 또는 `completed` |
| `video_files` | 연결 영상의 절대경로 (`|` 구분), 미지정 시 `null` |
| `active_video_file` | 현재 선택된 영상의 절대경로, 미지정 시 `null` |
| `trigger_frame` | 현재 선택 영상의 0-based 트리거 프레임, 미지정 시 `null` |
| `collision_frames` | 현재 선택 영상의 0-based 단일 충돌 프레임. 기존 호환성을 위해 복수형 칼럼명을 유지하며, 미지정 시 `null` |
| `video_markers` | 모든 영상의 단일 T/C 마커를 보존하는 JSON 객체. `collision_frames` 배열에는 최대 1개만 저장하며, 마커가 없으면 `null` |

## 다중 선택 표현

- 옵션별 CSV 칼럼이 있는 필드: 선택된 값 `1`, 미선택·미입력·비적용 값은 `null`
- 단일 CSV 칼럼 필드: 화면의 고정 옵션 순서로 `|` 연결
- `collision_target`: 범주 접두어 없이 요청서 선택값을 `승용|어른`처럼 연결
- 장애물 `무`: 장애물 객체 하위 칼럼은 `null`. 최초장애물 거리 3개 칼럼은 선택 입력값을 보존
- 블랙박스 근거: 기존 `data_list_Front_cam`, `data_list_Rear_cam`은 각각 자차 전방·후방에 사용하고, 타차 전방·후방은 `data_list_Other_Front_cam`, `data_list_Other_Rear_cam`에 기록
- 피해 `확인불가`: `incident_damage_Unknown=1`, 네 피해 수치 칼럼은 `null`
- 비고 탭의 사고 추가정보: `remarks` 칼럼에 글자 수 제한 없이 기록
- 부상급수: 경상 12~14급은 `incident_minor_injury_grade`, 중상 1~11급은 `incident_severe_injury_grade`에 각각 오름차순으로 기록. 각 인원수를 자동 집계하고 최솟값은 `incident_minor_representative_injury_grade`, `incident_severe_representative_injury_grade`에 분리 기록

CSV 파일에 기록되기 직전 모든 빈 셀은 소문자 문자열 `null`로 변환됩니다. 명시적으로 입력되거나 단일 이진 판정에서 계산된 `0`은 `null`로 바꾸지 않습니다.

CSV 칼럼 순서와 변환 구현은 `investigator.schema.csv_headers()` 및 `values_to_csv()`가 단일 기준입니다.

사고 표시 순서와 영상별 0°/90°/180°/270° 화면 회전 상태는 앱 재실행용 `investigations.json`에 저장하며 CSV 조사 칼럼에는 추가하지 않습니다. 회전은 원본 영상 파일에 적용되지 않습니다.

## 사용자 정의 조사 양식

`form_definition`에는 버전 3 양식 정의와 탭/필드의 안정적인 내부 key, 표시 이름, 입력 방식, 선택지, 기본값, 필수 여부, CSV 칼럼 및 이전 칼럼 별칭을 저장합니다. 기존 양식 버전 1·2는 자동으로 변환합니다. 이전에 1열로 고정됐던 식별 구분은 2열로 초기화하며, 이후 설정은 그대로 보존합니다.
`initial_form_definition`은 초기 설정 복원을 위한 독립된 기본 양식 사본입니다. 일반 양식 변경으로 갱신하지 않으며, 복원 시 사용자 추가 항목·선택지·기존 CSV 별칭과 사고 값은 유지합니다.
탭/항목 배열 순서가 화면 순서이며, 탭의 `columns`(1 또는 2)와 항목의 `full_width`로 배치를 지정합니다. 양식의 `csv_column_order`는 화면 재정렬과 독립적으로 기존 CSV 칼럼 순서를 보존합니다.
이전 양식은 트리거/충돌 탭을 2열로 초기화하고, 충돌 탭의 충돌대상·피해정도 확인불가를 전체 너비로 배치합니다. 이후 사용자가 수정한 순서·배치는 다시 초기화하지 않습니다.
사용자 정의 양식을 사용하는 프로젝트의 JSON `schema_version`은 2입니다. 양식 없는 기존 버전 1 파일은 기본 양식으로 로드합니다.

CSV의 앞부분은 기존 메타데이터 및 `schema.csv_headers()` 칼럼 순서를 그대로 유지합니다. 추가 필드와 CSV 이름 변경은 뒤쪽 추가 칼럼으로 제공하고, 기존 칼럼은 삭제하거나 이름을 바꾸지 않습니다.
선택지 표시 이름의 변경은 내부 저장값 및 기본 CSV 값에 영향을 주지 않습니다. 사용자 정의 다중 선택은 저장값을 `|`로 연결하며, 개별 CSV 칼럼이 있는 선택지는 선택 시 `1`, 미선택 시 `null`입니다.
사용자가 CSV 이름을 바꾼 항목의 내부 key와 값은 유지됩니다. 이미 저장한 사용자 정의 칼럼은 이름 변경 후에도 별칭으로 내보냅니다.
새 필수 항목 및 변경된 타입은 미입력 집계와 완료 검증에 적용합니다. 기존 값이 새 타입·선택지와 호환되지 않으면 양식 적용 자체를 거부하며, 기존 값은 자동 삭제/변환하지 않습니다.
양식 적용은 설정과 사고 데이터를 하나의 임시 JSON에 작성한 뒤 원자적으로 교체합니다. 저장에 실패하면 기존 파일과 화면을 유지합니다.
