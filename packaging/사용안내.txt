AVAT 사고 영상 조사 도구 - 사용 안내
=====================================

1. 폴더 구성
------------
AVAT\
  01_사고동영상\          조사할 영상을 넣는 곳. 이 안의 폴더 하나가 화면 위쪽 탭 하나입니다.
    (예) 2025년 1월\
    (예) 2025년 2월\
    작업관리\             조사 데이터(작업관리.db). 프로그램이 관리하므로 직접 수정하지 마세요.
  02_csv내보내기\         CSV 내보내기 기본 위치
  03_Report내보내기\      사고 분석 보고서 기본 위치
  systems\                프로그램 파일(AVAT.exe와 라이브러리)
    사용자데이터\         백업, 삭제한 영상, 설정, 로그. 업데이트할 때 반드시 보존하세요.

실행: systems\AVAT.exe


2. 설치 위치
------------
- 로컬 디스크의 짧은 경로에 두세요. 예: D:\AVAT
  (바탕화면이나 깊은 폴더 아래에 두면 Windows 경로 길이 제한(260자)에 걸려
   사고 삭제 등이 거절될 수 있습니다.)
- 같은 AVAT 폴더를 두 창에서 동시에 열 수 없습니다. 이미 실행 중이면 기존 창을 사용하세요.


3. 영상 넣기
------------
- 파일 이름은 13자리 사고번호로 합니다.
    2025010100001.mp4      사고 2025010100001의 영상
    2025010100001_1.mp4    같은 사고의 두 번째 영상
    2025010100001_2.mp4    같은 사고의 세 번째 영상
- 이 규칙에 맞지 않는 이름(예: IMG_0001.mp4)은 자동으로 사고가 되지 않습니다.
  필요하면 해당 사고를 선택한 뒤 "파일 → 현재 사고에 영상 추가"로 연결합니다.
- 01_사고동영상 아래 폴더에 영상을 복사하면 실행 중에도 자동으로 목록에 추가됩니다.
  영상을 수천 개씩 한꺼번에 넣을 때는 프로그램을 끈 상태에서 복사한 뒤 실행하는 편이 빠릅니다.
- 폴더(탭) 하나에 너무 많은 영상을 몰아 넣기보다 연도·월 단위 등으로 나누면 목록이 가볍습니다.


4. 백업과 불러오기
------------------
- 백업 파일은 작업 폴더당 1개만 유지합니다.
    systems\사용자데이터\백업\작업관리_백업.db
- 다음 때 자동으로 최신 상태로 바뀝니다.
    * 사고·영상 삭제 직전, 영상 경로 자동 복구 직전
    * 프로그램 종료, 다른 작업 폴더 열기(바뀐 내용이 있을 때만)
- 파일 → 조사 데이터 백업…
    기본 위치가 위 백업 파일입니다. 다른 위치(외장 저장장치 등)를 고르면 그곳에 별도 사본을 만듭니다.
    정기적으로 외장 저장장치에 사본을 보관하세요.
- 파일 → 조사 데이터 불러오기…
    백업 파일(.db)을 골라 현재 조사 데이터를 그 내용으로 바꿉니다.
    바꾸기 전의 현재 데이터는 위 백업 파일로 자동 저장됩니다.
    다른 PC의 01_사고동영상\작업관리\작업관리.db를 직접 골라도 됩니다(고른 파일은 바뀌지 않습니다).


5. 새 버전으로 업데이트
-----------------------
1) AVAT를 종료합니다.
2) 기존 systems\사용자데이터 폴더를 안전한 곳에 복사해 둡니다.
3) systems 폴더를 새 버전의 systems 폴더로 바꿉니다.
4) 2)에서 복사한 사용자데이터 폴더를 새 systems 폴더 안에 그대로 넣습니다.
5) 01_사고동영상 폴더(영상과 조사 데이터)는 그대로 둡니다.

※ 사용자데이터 폴더가 없는 이전 버전에서 처음 업데이트할 때
   2)와 4) 대신 기존 systems 폴더에 있는 아래 항목을 새 systems 폴더 안으로 옮깁니다
   (없는 항목은 건너뜁니다). 처음 실행할 때 사용자데이터 폴더로 자동 정리됩니다.
     backups\          이전 백업
     삭제사고\         삭제한 영상과 이동기록
     settings.ini      검출 설정
     workspace.json    영상 탭 순서·선택
     logs\             로그
   이전 자동 백업(삭제전-*, 영상경로변경전-*)은 가장 최근 1개만 작업관리_백업.db로 남고
   나머지는 정리됩니다. 오래된 백업도 보관하려면 옮기기 전에 backups 폴더를 따로 복사해 두세요.
   직접 만든 백업 파일은 그대로 남습니다.


6. 새 PC나 다른 폴더에 다시 설치하기
------------------------------------
1) 새 배포본을 원하는 위치(예: D:\AVAT)에 풉니다.
2) 기존 01_사고동영상 폴더의 영상 폴더들을 새 01_사고동영상 안으로 옮깁니다.
3) 기존 systems\사용자데이터 폴더를 새 systems 폴더 안에 넣습니다.
   (백업 파일만 있다면 systems\사용자데이터\백업\작업관리_백업.db 위치에 넣습니다.
    기존 작업관리.db를 이 이름으로 바꿔 넣어도 됩니다.)
4) AVAT를 실행합니다. 조사 데이터(작업관리.db)가 없으면 위 백업 파일에서 자동으로 복원합니다.
   기존 작업관리 폴더째 옮겼다면 그 데이터를 그대로 사용합니다.
- 이미 실행해서 새 데이터가 생긴 뒤라면 "파일 → 조사 데이터 불러오기…"로 백업 파일을 고릅니다.
- 영상 위치가 바뀌었으면 같은 파일 이름을 찾아 자동으로 다시 연결합니다.


7. 삭제한 영상
--------------
- 사고나 영상을 삭제하면 영상 파일은 지워지지 않고 아래 폴더로 옮겨집니다.
    systems\사용자데이터\삭제사고\<날짜-시각-번호>\
- 같은 폴더의 이동기록.json에 원래 위치가 적혀 있습니다.
- 공간이 부족하면 필요 없는 항목을 직접 정리하세요(정리 후에는 되돌릴 수 없습니다).


8. 문제 해결
------------
- "다른 AVAT 창에서 이 작업 폴더를 사용 중입니다"
    열려 있는 다른 AVAT 창을 닫고 다시 실행하세요. 비정상 종료로 남았거나 다른 PC에서 폴더째
    복사돼 온 잠금은 자동으로 풀립니다. 열린 창이 없는데도 계속 나오면 작업 관리자에서
    남아 있는 AVAT.exe를 종료하세요.
- "조사 데이터베이스를 읽을 수 없습니다"
    "파일 → 조사 데이터 불러오기…"로 백업 파일을 고르세요. 읽을 수 없던 기존 데이터는
    01_사고동영상\작업관리\작업관리_읽기오류_<날짜>.db 로 보존됩니다.
- 문의할 때는 systems\사용자데이터\logs\avat.log 파일을 함께 보내 주세요.
  (로그에는 사고번호·입력값·영상 파일명이 기록되지 않습니다.)
- NVIDIA 그래픽 카드가 없는 PC에서는 객체 검출이 CPU로 실행되어 느립니다.
