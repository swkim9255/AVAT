AVAT (Accident Video Analysis Tool) Windows 배포본 안내
=====================================================

이 폴더는 Python을 설치하지 않은 Windows 10/11 64비트 PC에서, 인터넷 연결 없이
실행할 수 있도록 묶은 배포본입니다. Python·Qt(PySide6)·OpenCV·NumPy·PyTorch·
Torchvision·Transformers 등 실행 라이브러리는 모두 _internal 폴더에 들어 있습니다.
객체 검출 모델(Grounding DINO) 가중치만 별도로 넣습니다.


1. 폴더 구성
------------
AVAT.exe                               실행 파일
_internal\                             내장 라이브러리 (수정·삭제 금지)
detection-runtime.json                 객체 검출 설정 (Grounding DINO, 로컬 모델, 오프라인)
runtime\models\grounding-dino-base\    모델 7개 파일을 넣는 곳
prerequisites\vc_redist.x64.exe        Microsoft Visual C++ 재배포 패키지 (필요한 PC만)
licenses\                              제3자 고지, 포함 패키지 라이선스, 빌드 패키지 목록
BUILD-INFO.txt                         빌드 시각·소스 커밋·PyTorch 종류(CPU/CUDA)
SHA256SUMS.txt, verify-package.ps1     반입 후 무결성 확인


2. 설치 순서
------------
(1) AVAT 폴더 전체를 C:\AVAT 처럼 쓰기 가능한 로컬 드라이브에 복사합니다.
    네트워크 드라이브·USB에서 바로 실행하지 마세요. 폴더 이름은 바꿔도 됩니다.

(2) 모델 7개 파일을 runtime\models\grounding-dino-base\ 에 복사합니다.
      config.json
      model.safetensors            (약 930MB)
      preprocessor_config.json
      special_tokens_map.json
      tokenizer.json
      tokenizer_config.json
      vocab.txt
    model.safetensors 하나만 복사하면 실행되지 않습니다. 다운로드용 .cache 폴더는 필요 없습니다.

(3) (권장) 무결성 확인: AVAT 폴더에서 PowerShell을 열고
      powershell -ExecutionPolicy Bypass -File .\verify-package.ps1
    "확인 완료"가 나오면 프로그램 파일과 모델 파일이 모두 정상입니다.

(4) AVAT.exe를 실행합니다. 작업 폴더를 지정하려면 바로가기 대상에 인자를 추가합니다.
      C:\AVAT\AVAT.exe --workspace "D:\investigations"


3. 객체 검출 확인
-----------------
- 프로그램 폴더의 detection-runtime.json이 자동으로 적용됩니다. 별도 설정은 필요 없습니다.
- 설정 → 객체 검출 환경…에서 "검출용 Python" 칸은 비워 둡니다(비우면 AVAT 내장 환경 사용).
  모델 경로가 이 폴더의 runtime\models\grounding-dino-base 인지, "오프라인 실행"이 켜져
  있는지 확인합니다.
- 이 PC에서 예전에 다른 모델·경로를 저장해 둔 적이 있다면 그 설정이 우선할 수 있습니다.
  위 화면에서 Grounding DINO와 이 폴더의 모델 경로로 바꾸고 확인을 누르세요.
- 검출은 영상 일부 프레임을 별도 프로세스(AVAT.exe를 한 번 더 실행)로 처리합니다.
  작업 관리자에 AVAT.exe가 여러 개 보이는 것은 정상입니다.


4. CPU판과 GPU(CUDA)판
----------------------
BUILD-INFO.txt의 "PyTorch 종류"에서 확인합니다.
- CPU판: 모든 PC에서 CPU로 검출합니다. 용량이 작고, 검출은 GPU보다 느립니다.
- CUDA판: NVIDIA GPU가 있으면 GPU로 검출합니다. CUDA 12.8을 지원하는 NVIDIA 드라이버
  (R570 이상 권장)가 필요합니다. GPU가 없거나 드라이버가 맞지 않으면 자동으로 CPU를 사용합니다.
  CUDA Toolkit은 따로 설치하지 않습니다.


5. 실행되지 않을 때
-------------------
- "VCRUNTIME140.dll" / "MSVCP140.dll"이 없다는 오류, 또는 아무 반응이 없을 때:
  prerequisites\vc_redist.x64.exe를 관리자 권한으로 설치한 뒤 다시 실행합니다.
- "Windows의 PC 보호"(SmartScreen) 창: 서명되지 않은 실행 파일이라 나타날 수 있습니다.
  [추가 정보] → [실행]을 누르거나, 기관 보안 정책에 따라 예외 등록을 요청합니다.
- 백신이 AVAT.exe 또는 _internal 안의 파일을 격리하면 실행·검출이 실패합니다.
  verify-package.ps1로 누락 파일을 확인하고 예외 등록을 요청하세요.
- 진단 로그: %LOCALAPPDATA%\AVAT\logs (문제 보고 시 이 폴더를 함께 전달)


6. 업데이트와 제거
------------------
- 업데이트: 새 배포본 폴더로 교체하고 runtime\models\grounding-dino-base\의 모델 파일만
  옮겨 넣습니다. 조사 데이터(investigations.db)는 작업 폴더에 있으므로 영향이 없습니다.
- 제거: AVAT 폴더를 삭제합니다. 사용자 설정은 레지스트리 HKCU\Software\AVAT,
  로그는 %LOCALAPPDATA%\AVAT에 남으며 필요하면 직접 지웁니다.
