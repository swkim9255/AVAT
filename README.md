# Accident Video Analysis Tool (AVAT)

사고별 영상을 프레임 단위로 검토하면서 조사 항목을 입력하고, 임시저장·완료 처리한 결과를 CSV로 내보내는 PySide6 데스크톱 앱입니다.

## 주요 기능

- 13자리 사고번호 파일명을 기준으로 폴더 영상을 사고별 자동 분류
- 사고 목록과 사고별 복수 영상 관리, 확인 절차가 있는 사고·영상 삭제
- 메뉴·작업 폴더 탭·조사/통계 보기 전환을 한 줄로 배치, 현재 탭/새 탭 열기 선택
- 프로젝트 폴더의 새 영상 자동 감지, 가져오기 시 작업 폴더로 복사 선택
- OpenCV 기반 재생/일시정지, 영상 소리 출력, ±1/10프레임, ±1초 이동, 프레임 번호 직접 이동
- 영상마다 트리거 `T` 1개와 충돌 `C` 1개 타임라인 마커 지정·저장
- 영상별 속도 기준 지점·구간 거리 입력, 구간 평균 속도와 T 시점 속도 추정·그래프
- 식별 구분을 우측 상단에 고정하고 조사 항목과 자유 텍스트 비고를 9개 탭으로 제공
- 사고 구분 번호 최대 13자리와 `20-24세`~`95-99세`의 5세 단위 운전 연령 선택
- 사고 당시 주행거리는 자리수 제한 없이 숫자로 입력
- 트리거 시점 사고 정보의 2열 입력 배치
- 숫자·길이·실제 날짜/시간·요일 일치 검증
- 거리 수치에 따른 범위와 사고일자(직접 입력·달력 선택)에 따른 요일 자동 입력
- 일요일부터 시작하는 달력과, 사고일자 아래의 회색 읽기 전용 사고요일 표시
- 장애물 유무 및 피해 확인 가능 여부에 따른 조건부 입력
- 논리적 필수 질문 기준의 `미입력 N` 표시
- SQLite 트랜잭션 기반 사고별 부분 저장, 완료 상태 관리, 다음 미완료 사고 이동
- 사고 1건당 1행의 UTF-8 BOM CSV 내보내기
- 선택한 사고별 Word 사고 분석 보고서(.docx) 자동 생성
- 프로젝트별 통계 탭: 개요·항목 분석·교차 분석·영상 지표·데이터 품질
- 통계 그래프/표에서 사고 조사로 이동, 조건 필터, PNG·CSV·PDF 내보내기

## 설치 및 실행

Python 3.11~3.13 환경을 권장합니다.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python main.py
```

작업 폴더를 지정해 실행할 수도 있습니다.

```powershell
python main.py --workspace "D:\investigations"
```

처음 실행할 때 작업 폴더를 지정하지 않으면 Windows 문서 폴더 아래 `사고영상조사`를 사용하며, 이후에는 저장된 프로젝트 탭을 복원합니다. 앱의 **파일 → 프로젝트 폴더 열기**, 상단 **+** 또는 `Ctrl+O`로 프로젝트 폴더를 열 수 있습니다. 폴더를 선택하면 **현재 탭으로 불러오기 / 새 탭에서 열기**를 선택하며 기본 선택은 새 탭입니다. 이미 열린 폴더를 선택하면 해당 탭으로 이동합니다.

각 프로젝트는 자신의 폴더에 있는 `investigations.db`를 사용합니다. 메뉴 오른쪽의 배경색이 있는 문서 탭을 누르면 사고 목록·조사 양식이 전환되며, 전체 경로는 탭에 마우스를 올려 확인합니다. 긴 탭 이름은 가운데를 생략하고, 탭이 많으면 좌우 스크롤로 탐색합니다. 폴더명·경로를 메뉴나 왼쪽 패널에 중복 표시하지 않으며 왼쪽은 **사고 / 영상 목록**으로 시작합니다. 맨 오른쪽의 **조사 / 통계**는 문서 탭과 구분되는 두 칸 토글 버튼입니다. 탭의 닫기 버튼으로 프로젝트를 닫을 수 있으며, 마지막 프로젝트의 닫기 버튼은 비활성화됩니다. 현재 탭에서 다른 프로젝트를 열어도 이전 프로젝트의 저장 데이터는 해당 폴더에 보존됩니다.

프로젝트 폴더 탭을 좌우로 드래그하면 표시 순서를 바꿀 수 있습니다. 순서만 변경할 때는 현재 프로젝트의 입력 내용·영상 재생 상태·통계 조건을 유지하며, 사고 순서나 저장 폴더는 바뀌지 않습니다.

탭 전환·현재 탭 교체·탭 닫기 전에 변경 사항을 저장하며 실패하면 동작을 취소합니다. 탭을 오갈 때 검색어·사고 목록 펼침/선택 상태·조사 탭·영상 프레임을 복원하고 영상은 일시정지 상태로 엽니다. 비활성 프로젝트의 영상 디코더는 닫습니다.

열린 프로젝트 폴더 탭·드래그로 변경한 순서·마지막 선택 탭은 앱을 다시 실행해도 복원됩니다. Windows에서는 `%LOCALAPPDATA%\AVAT\project_tabs.json`에 폴더 경로와 선택 위치만 별도로 저장하며 사고 데이터는 각 폴더의 `investigations.db`에 그대로 유지합니다. 탭을 열거나 닫고 이동할 때 자동으로 기록하고, 정상 종료 시에도 최종 상태를 저장합니다. 재실행 시 선택된 프로젝트만 먼저 읽고 다른 탭은 선택할 때 읽습니다. `--workspace`를 지정하면 기존 탭은 유지한 채 해당 폴더를 선택하며, 처음 보는 폴더는 새 탭으로 추가합니다. 저장된 폴더가 없거나 외장 드라이브가 연결되지 않았으면 탭을 유지하고 읽기 오류를 표시하며, 없는 폴더를 자동 재생성하거나 기존 데이터를 덮어쓰지 않습니다. 연결 복구 후 같은 폴더를 다시 열면 재시도합니다. 검색어·통계 조건 등 실행 중 화면 상태까지 이 설정 파일에 저장하지는 않습니다.

## 기본 사용 흐름

1. 프로젝트 폴더를 처음 열면 그 폴더 바로 아래의 영상을 자동으로 검색합니다. 다른 위치의 원본 영상은 **파일 → 현재 사고에 영상 추가**나 드래그앤드롭으로 추가합니다. 기관은 `samsung`으로, 파일명의 13자리 숫자는 사고 구분 번호로 자동 입력됩니다.
2. `1234567890123.mp4`, `1234567890123_1.mp4`, `1234567890123_2.mp4`처럼 같은 사고번호를 가진 영상은 한 사고에 묶이고, 기본 영상과 뒤쪽 번호 순서로 정렬됩니다. 파일 메뉴의 **현재 사고에 영상 추가**나 드래그앤드롭으로 개별 영상을 직접 연결할 수도 있습니다.
3. 왼쪽 사고 항목을 위·아래로 드래그하면 표시 순서가 바뀌며, 변경된 순서는 작업 DB에 저장됩니다.
4. 중앙 영상 플레이어 아래 컨트롤이나 단축키로 필요한 프레임을 찾습니다. 플레이어 상단의 회전 아이콘을 누를 때마다 현재 영상이 시계 방향으로 90°씩 회전하며, 0° → 90° → 180° → 270° 순서로 순환합니다.
5. **T 지정**, **충돌 지정**으로 조사 기준 시점을 기록합니다. 다른 프레임을 지정하면 기존 시점이 교체되고, 같은 프레임에서 다시 누르면 해당 마커가 해제됩니다. 타임라인의 `T` 또는 `C` 마크를 클릭하면 해당 프레임으로 이동하며, 마우스를 올리면 강조색·포인터 커서·프레임 안내가 표시됩니다.
6. 우측 식별 영역과 9개 탭의 조사 항목을 입력합니다. **비고** 탭에는 글자 수 제한 없이 사고 추가정보를 입력할 수 있습니다.
7. 오른쪽 조사 패널 하단에서 **임시저장**, 검증을 통과한 뒤에는 **완료**를 누릅니다.
8. **다음**으로 다음 미완료 사고로 이동하고, 마지막에 **조사 결과 CSV 내보내기**를 사용합니다.

왼쪽 목록에서 사고나 개별 영상을 선택하면 **사고 삭제** 또는 **영상 삭제** 버튼이 표시됩니다. 삭제 전 확인을 거치며, 영상을 목록에서 삭제해도 디스크의 원본 영상 파일은 삭제하지 않습니다. 삭제한 영상은 작업 폴더를 다시 열어도 자동 복원되지 않으며, **현재 사고에 영상 추가**를 명시적으로 사용하면 다시 연결할 수 있습니다.

빈 작업 폴더는 사고 `0건`으로 시작하며 `SAMSUNG-001`을 자동 생성하지 않습니다. **새 사고**를 눌렀을 때만 수동 입력용 사고를 만들고, 마지막 사고도 실제로 삭제할 수 있습니다. 이전 버전에서 `SAMSUNG-001`에 잘못 연결된 13자리 파일명 영상은 작업 폴더를 열 때 파일명의 사고번호로 자동 이관하며 영상별 마커도 함께 보존합니다.

화면에 표시되는 프레임 번호는 사람이 읽기 쉬운 1부터 시작하고, DB와 CSV의 마커 프레임은 영상 처리 호환을 위해 0부터 시작합니다.

## 트리거 시점 속도 추정

플레이어 아래의 **속도 지점** 또는 **M**으로 현재 프레임에 기준 지점을 추가합니다. 차량이 도로의 기준물을 지나는 순간을 골라, **같은 차량 기준점**으로 측정하세요. 같은 프레임에서 다시 누르면 그 지점이 해제됩니다. 지점을 추가하면 측정 패널이 열리며 계기판 아이콘으로 접거나 펼칠 수 있습니다.

1. 첫 지점은 시작점입니다. 두 번째 지점부터 **이전 지점부터 거리(m)**에 실제 기준물 사이 거리를 입력합니다. 뒤에 추가하는 지점은 직전에 사용한 거리를 편의상 복사하므로, 각 구간의 실제 거리와 일치하는지 확인하세요. 도로 표식 길이를 자동으로 가정하거나 영상을 자동 분석해 거리를 구하지는 않습니다.
2. 각 구간의 평균 속도는 `거리 ÷ (프레임 차 / 실제 FPS) × 3.6`으로 표시합니다.
3. **T 지정**을 하면 T 시점 속도를 계산합니다. 가까운 지점 최대 4개로 등가속도 위치 모형을 근사하며, 두 지점만 있으면 구간 평균을 사용합니다. 모형의 가속도 변화가 지나치게 크면 가까운 구간 평균으로 대체하고 경고합니다. 거리가 누락된 구간은 서로 연결하지 않습니다.
4. 그래프에는 구간 평균, T 근사선·추정값, 속도 구분 경계를 표시합니다. 타임라인의 번호, 표의 프레임·시각, 그래프의 지점 번호를 누르면 해당 프레임으로 이동합니다. **선택 삭제**, 확인 후 **모두 삭제**도 가능합니다.
5. **차량 속도에 적용**을 눌렀을 때만 트리거 탭의 속도 구분과 출처를 ‘사고영상’으로 입력합니다. 기존 EDR/보고서 출처를 바꾸거나 외삽·불안정한 추정값을 적용할 때는 확인을 받습니다. 사용자 정의 선택지의 저장값도 반영합니다.

실제 FPS를 확인할 수 없으면 재생용 대체 FPS로 속도를 계산하지 않습니다. 계산은 일정한 프레임 간격을 가정하므로 가변 FPS 영상에서는 정확한 시간 정보가 별도로 필요할 수 있습니다. 표시 범위는 **각 지점 ±0.5프레임 배치 가정의 민감도**이며, 거리 오차·모델 오차를 포함한 신뢰구간이나 감정 결과가 아닙니다. T가 측정 범위 밖이거나 지점이 지나치게 가까우면 경고를 확인하고 기준물을 다시 점검하세요.

측정 지점과 거리는 **영상별로** DB의 기존 마커 안에 선택 항목 `speed_points`로 저장되며 재실행 후 복원됩니다. 추정 수치는 영상을 열 때 실제 FPS로 다시 계산합니다. 기존 DB·JSON을 읽을 수 있고 조사 CSV의 칼럼 순서도 유지합니다. CSV의 `video_markers` JSON 안에 속도 지점을 포함하며, 구버전 앱에서 다시 저장하면 새 속도 지점 정보가 보존되지 않을 수 있습니다. 원본 영상은 변경하지 않습니다.

좁은 창에서는 프레임·마커 버튼을 두 줄로, 측정 표와 그래프를 세로로 배치합니다. 측정 패널 내부만 스크롤하므로 조사 입력 사이드바를 침범하지 않습니다.

## 통계 분석

상단 **조사 / 통계** 탭으로 전환합니다. 현재 프로젝트의 실제 조사 값을 사용하며, 기본 집계 대상은 **완료** 사고입니다. 임시저장 사고를 포함하거나 사고일자 기간, 조사 항목별 조건을 추가할 수 있습니다. 여러 조건은 모두 만족하는 사고만 포함합니다. 아직 저장하지 않은 입력도 화면 집계에 반영되지만 통계 탭을 여는 것만으로 완료 처리하거나 저장 데이터를 변경하지는 않습니다.

- **개요**: 사고 수, 인명피해 사고 수, 평균 트리거→충돌 시간, 필수 미입력 사고 수와 고정한 항목의 분포를 확인합니다.
- **항목 분석**: 항목 검색·입력률, 건수·비율·표 보기, 막대 가로/세로 전환을 제공합니다. 명목 단일 선택의 표시 범주가 5개 이하일 때는 클릭 가능한 파이(도넛) 보기도 제공합니다. 숫자 구간 분포와 평균·중앙값·사분위수를 확인하며, 사용자 정의 탭·항목과 수정한 선택지 이름도 반영합니다. 항목을 개요에 고정하거나 해제할 수 있습니다.
- **교차 분석**: 항목 유형에 따라 자동으로 보기를 바꿉니다. 범주×범주는 히트맵 또는 100% 누적 막대, 범주×수치는 상자수염과 개별 사고 점, 수치×수치는 산점도와 최소제곱 추세선입니다. 예시 조합·행열 바꾸기·같은 항목 선택 안내와 실제 사고 드릴다운을 제공합니다. 열이 다중 선택이면 사고 비율이 100%를 넘을 수 있어 누적 막대 대신 히트맵을 사용합니다. 각 축 100개 범주 또는 2,500칸을 넘는 교차표와 100개를 넘는 상자 그룹은 필터로 범위를 줄이도록 안내하며 임의로 일부 값만 집계하지 않습니다.
- **나비형 비교**: 교차 분석에서 선택합니다. 가운데 축의 분포를 왼쪽 파란색·오른쪽 주황색 막대로 비교하며, 두 그룹 또는 한 그룹 vs 나머지, 그룹 내 비율(기본) 또는 건수로 전환할 수 있습니다. 좌우는 동일한 눈금을 쓰고 분모는 각 그룹의 사고 수입니다. 수치 항목은 공통 구간으로 나누고 운전 연령 등은 기존 순서를 유지합니다. 그룹 미입력·오류·비해당은 제외하며, 다중 선택 그룹의 중복과 20건 미만 그룹을 안내합니다. 막대에 마우스를 올리면 건수·비율·분모가 표시되고, 누르면 해당 그룹의 실제 사고, 가운데 구간을 누르면 좌우 사고를 중복 없이 확인합니다. 선택 구간과 가장 큰 비율 차이를 표시하며 PNG·CSV 내보내기도 지원합니다. 비교 설정은 실행 중 프로젝트 탭별로 유지됩니다.
- **영상 지표**: 연결된 모든 영상의 T·C 지정률과, 사고별 현재 선택 영상의 시간 차를 집계합니다. 시간은 `(충돌 프레임 - 트리거 프레임) / 실제 FPS`로 계산합니다. FPS 미확인·마커 누락·역순 영상은 시간 계산에서 제외하며, 재생용 대체 FPS를 통계에 사용하지 않습니다. 영상 정보 확인은 별도 스레드에서 수행하며 원본 파일을 수정하지 않습니다.
- **데이터 품질**: 상태 필터와 무관하게 전체 작업 상태를 확인합니다. 기간·추가 조건은 적용합니다. 조건부 필수 항목별 실제 해당 건수·입력률·미입력·오류를 표시하며, 선택 항목과 조건상 해당 없는 항목은 필수 미입력 집계에서 제외합니다. 문제 사고를 누르면 조사 화면의 확인할 항목으로 이동합니다.

교차 분석의 **읽는 법**은 관측 분포와 참고용 검정 결과를 함께 보여 줍니다. 범주×범주는 Pearson 카이제곱(연속성 보정 없음)·크라메르 V, 범주×수치는 동순위 보정 크러스컬–월리스, 수치×수치는 Pearson 상관·양측 p값을 사용합니다. 카이제곱은 유효 20건 미만, 크러스컬–월리스는 그룹별 5건 미만, 상관은 유효 쌍 3건 미만이면 검정을 제한합니다. 미입력·형식 오류·비해당은 검정에서 제외하고, 그룹에 같은 사고가 중복되면 독립 표본 검정을 하지 않습니다. 희소한 기대 빈도·상수 값 등은 별도로 안내합니다. 검정과 추세선은 인과관계나 감정 결과를 뜻하지 않습니다.

연속 수치인 **T 시점 추정 속도(km/h)**는 현재 선택 영상에 저장된 속도 지점·거리·T와 실제 FPS로 다시 계산합니다. 기존의 정차·크립·저속·중속·고속 구분을 임의의 수치로 변환하지 않습니다. 측정값 또는 실제 FPS가 없으면 수치 속도를 포함한 분석에서 제외하며, 기존 조사 값은 바꾸지 않습니다. 상자그림 그룹과 산점도 점은 유효 수치가 있는 사고만 보여 주므로, 해당 드릴다운은 필터 고정 없이 조사 열기만 제공합니다.

막대·표의 칸을 누르면 오른쪽에 해당 사고 목록이 표시됩니다. 사고를 눌러 조사 화면으로 이동하거나 **이 조건을 필터로 고정**할 수 있습니다. 다중 선택은 항목마다 사고를 한 번씩 세므로 비율의 합이 100%를 넘을 수 있습니다. 비율 분모와 미입력·해당 없음 수를 함께 표시합니다. 숫자 구간은 이상·미만 기준입니다.

**내보내기**에서 현재 보기의 그래프/표 이미지(PNG), 전체 집계 표(CSV), 개요 요약과 고정 항목 표(PDF)를 저장합니다. PNG·PDF에는 필터와 집계 기준을 표시하며, 통계 CSV는 조사 결과 CSV와 별도의 집계용 파일입니다. 프로젝트별 통계 조건·고정 항목·보기는 실행 중 탭 전환 시 유지됩니다. 앱 재실행 시에는 기본 보기로 시작합니다.

화면은 제공된 통계 시안의 밝은 회색 배경, 흰색 카드, 절제된 파란색 강조와 공통 입력·버튼 스타일로 통일했습니다. 기존 조사 입력·재생·저장 방식과 CSV 스키마는 유지합니다. 추가 패키지 설치는 필요하지 않습니다.

## 사고 분석 보고서 내보내기

왼쪽 **사고 분석 보고서 내보내기** 또는 **파일 → 사고 분석 보고서 내보내기…**를 누릅니다.
선택 창에서 보고서로 만들 사고들을 체크한 뒤 **저장 폴더 선택…**으로 출력 위치를 지정합니다.
현재 목록에서 선택한 사고·영상의 부모 사고를 먼저 체크하며, 검색과 전체 선택/해제를 지원합니다.
현재 프로젝트의 사고만 대상으로 하고, 작성 중인 사고도 내보낼 수 있습니다.

사고마다 `SAMSUNG-사고번호_사고분석보고서.docx`를 생성합니다. 같은 파일이 있으면 `_2`, `_3`을
붙여 기존 보고서를 보존합니다. 현재 입력 내용을 사용하되 조사 데이터의 저장·완료 상태는 바꾸지 않습니다.
미입력 텍스트는 `-`, 실제 숫자 0은 `0`으로 구분하고, 선택 항목은 Word 체크박스에 반영합니다.
사고일자는 `YYYY-MM-DD`, 시간은 `HH:MM`으로 표시하며 요일은 날짜로 계산합니다.

제공된 양식을 `investigator/assets/사고분석보고서.docx`에 포함했습니다. 38개 텍스트 변수와
85개 체크박스를 연결하며 표·글꼴·페이지 설정과 원본 양식은 보존합니다. Word가 설치되지 않은
컴퓨터에서도 내보낼 수 있고 추가 Python 패키지는 필요하지 않습니다.

양식의 `{{항목키}}`는 조사 항목의 안정적인 내부 키와 연결됩니다. 현재/기존 CSV 칼럼명도
지원하되 같은 이름이면 내부 키가 우선합니다. `{{incident_hour}}`는 `incident_time`의 별칭입니다.
예를 들어 `{{vehicle_fuel}}`는 사용연료, `{{vehicle_mileage}}`는 주행거리, `{{remarks}}`는 비고입니다.
체크박스 콘텐츠 컨트롤의 태그는 개별 CSV 칼럼명 또는 `CSV칼럼명|선택지`로 연결합니다.
조사 항목 편집에서 라벨·선택값·CSV명을 바꿔도 기존 항목의 연결은 유지합니다.
기본 양식에 칸이 없는 대표부상급수·영상 마커·사용자 추가 항목은 임의로 덧붙이지 않습니다.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 재생 / 일시정지 | `Space` |
| ±1프레임 | `←` / `→` |
| ±10프레임 | `Ctrl+←` / `Ctrl+→` |
| ±1초 | `J` / `L` |
| 속도 지점 추가 / 해제 | `M` |
| 임시저장 | `Ctrl+S` |

입력 필드에 포커스가 있거나 통계 화면을 보고 있을 때는 재생 단축키가 입력을 가로채거나 숨겨진 영상을 재생하지 않습니다.

영상에 음성 트랙이 있으면 시스템 기본 출력 장치로 소리를 재생합니다. 일시정지·탐색·영상 전환 시 소리도 함께 제어하며, 음성 트랙이 없는 영상은 무음으로 재생합니다. 재생바 드래그 시 손잡이·요청 시각은 즉시 반영하고 영상은 비동기로 갱신합니다. 일시정지 중에는 오디오 탐색을 반복하지 않고, 재생을 시작할 때 최종 위치에 맞춥니다. 영상 디코딩은 별도 프로세스의 FFmpeg 자동 병렬 설정을 사용합니다.

오디오 백엔드의 초기화 안내와 영상 메타데이터 출력은 숨깁니다. 파일 시간 정보 경고나 디코딩 오류 등 경고·오류 로그는 유지합니다.

프로젝트 폴더의 자동 검색은 폴더 바로 아래에 있는 지원 영상 파일을 읽습니다. 이름이 `13자리 숫자` 또는 `13자리 숫자_1`, `_2` 형식이 아닌 영상은 건너뛰며, 같은 폴더를 다시 열어도 기존 사고와 영상은 중복 생성되지 않습니다.

열려 있는 프로젝트 폴더는 `QFileSystemWatcher`로 감시합니다. 폴더 바로 아래에 새 영상이 생기면 크기·수정 시간이 2초 동안 안정되고 읽을 수 있는지 확인한 뒤, 기존 13자리 사고번호 규칙에 따라 자동으로 추가·저장합니다. 하위 폴더는 감시하지 않으며, 파일 복사가 잠시 멈춘 경우에는 이 안정화 시간만으로 복사 완료를 확정할 수 없습니다. 기존 영상 파일을 삭제해도 조사 기록을 자동 삭제하지는 않습니다. 목록에서 직접 삭제한 영상·사고의 제외 설정은 자동 갱신에도 적용합니다.

현재 프로젝트의 자동 갱신은 수정한 목록 행과 새 사고만 반영하고 입력 중인 값·선택 사고·영상 재생 위치를 유지합니다. 다른 프로젝트 탭에서 새 영상이 감지되면 탭 이름에 `•`가 표시되고 해당 탭으로 이동할 때 반영합니다. 저장·복사·대화상자 처리 중에는 갱신을 보류하며, 저장 실패 시 입력값을 유지하고 잠시 후 다시 시도합니다.

**현재 사고에 영상 추가**, 영상 드래그앤드롭으로 가져올 때 나타나는 옵션에서 **작업 폴더로 복사**를 선택할 수 있습니다. 기본값은 선택하지 않은 연결형입니다. 선택하면 원본은 그대로 두고 현재 프로젝트 폴더에 파일을 복사한 뒤 복사본을 연결합니다. 개별 추가는 일반 파일명도 지원합니다. 같은 이름의 내용이 다른 파일은 순번을 붙이며, 13자리 사고번호는 유지합니다. 기존 파일과 내용이 같으면 해당 파일을 재사용합니다. 복사는 임시 파일에 완료한 뒤 최종 이름으로 반영하고, 복사·조사 데이터 저장 실패 시 이번에 생성한 복사본을 정리합니다. 복사 작업은 별도 작업 스레드에서 수행합니다.

## 저장 형식과 완료 기준

**설정 → 조사 항목 편집…** 또는 사고 조사 입력 제목 옆 편집 버튼에서 현재 작업 폴더의 양식을 변경할 수 있습니다.
왼쪽에서 탭·항목을 선택해 탭 제목/라벨, 항목 이름, CSV 칼럼명, 입력 방식, 필수 여부, 선택지와 기본값을 편집합니다.
**탭 추가**, **항목 추가**로 양식을 확장하고 **양식 적용 및 저장**을 누르면 즉시 화면에 반영됩니다. 취소하면 적용되지 않습니다.
왼쪽에서 탭 또는 항목을 선택하고 **▲ / ▼**로 순서를 변경할 수 있습니다. 항목은 해당 탭 안에서 이동하며, 상단 식별 구분 영역은 고정됩니다.
식별 구분의 기본 배치는 기관코드와 사고 구분 번호가 나란히 표시되는 2열입니다. 편집창의 식별 구분 → 항목 배치에서 1열/2열을 선택할 수도 있습니다.
**초기 설정 복원**은 `investigations.db`의 `initial_form_definition` 설정에 별도로 보관한 기본 양식의 이름·입력 방식·기본값·순서·배치를 불러옵니다. 복원 기준은 양식을 편집해도 변경되지 않습니다. 기존 작업 폴더에는 이 버전의 기본 양식을 초기값으로 추가합니다.
**초기 설정 복원**을 누르면 확인창이 표시되며 기본 선택은 ‘아니요’입니다. ‘예’를 선택하면 편집창에서 복원 결과를 확인할 수 있고, **양식 적용 및 저장**으로 확정합니다. 취소하면 편집 중인 내용도 그대로 유지합니다. 추가한 탭·항목·선택지와 조사 값 및 CSV 별칭은 유지합니다. 기존 조사 값이 초기 입력 방식과 맞지 않으면 일반 양식 편집과 동일하게 적용을 막고 해당 항목을 안내합니다.
탭의 **항목 배치**에서 1열(세로) 또는 2열(좌우)을 선택합니다. 2열은 목록 순서대로 왼쪽 → 오른쪽으로 배치하며, 항목별 **한 행 전체 너비 사용**으로 특정 항목만 전체 너비를 사용할 수 있습니다.
충돌 탭은 충돌대상 → 피해정도 확인불가를 전체 너비로 표시하고, 경상·중상 부상급수/대표급수/인원 및 사망·물적피해 항목을 좌우에 배치합니다. 순서·배치는 작업 폴더에 저장되며 재실행 시 복원됩니다. 화면 순서 변경은 CSV 칼럼 순서를 바꾸지 않습니다.
입력 방식은 드롭다운, 정수·소수, 한 줄·여러 줄 텍스트, 체크박스/다중 선택을 지원합니다. 선택지의 표시 이름과 저장값은 별개이며, 기본값은 저장값으로 입력합니다(다중 선택은 한 줄에 하나).

양식은 `investigations.db`의 `form_definition` 설정에 사고 데이터와 함께 저장되어 재실행 시 복원됩니다. 다른 작업 폴더에는 영향을 주지 않습니다.
기본값은 이후 생성하거나 가져오는 새 사고에만 적용하며 기존 사고나 사용자가 비운 값은 덮어쓰지 않습니다.
기존 값에 맞지 않는 입력 방식·선택지 변경은 적용되지 않습니다. 새 필수 조건 때문에 완료 조건을 충족하지 못하는 사고는 미완료로 전환되고 입력 내용은 유지됩니다.

호환성을 위해 내부 항목 식별자는 고정합니다. 항목 자체의 CSV 칼럼명 변경은 기존 별칭을 유지하며, 사용자 정의 항목은 뒤에 추가합니다. 선택지의 **개별 CSV 칼럼**을 변경하면 해당 위치의 헤더를 새 이름으로 교체하며 이전 이름의 칼럼을 중복 출력하지 않습니다.
빈 값은 기존과 같이 `null`로 출력합니다. 선택지의 저장값을 바꾸면 텍스트형 CSV에는 바꾼 저장값을 출력합니다. 기본 충돌 대상은 기존처럼 범주 접두어를 뺀 선택값을 `|`로 연결합니다. 개별 선택 여부 칼럼은 `1`/`null`을 유지합니다.
날짜·요일, 부상급수, 조건부 질문, 선택지별 CSV 분리 항목은 자동 계산에 필요한 입력 방식과 필수 규칙을 보호합니다. 선택지의 표시 이름·저장값·개별 CSV 칼럼은 편집할 수 있습니다. 저장값을 바꾸면 기존 조사 결과와 기본값의 선택도 함께 옮기며, 조건부 질문과 자동 계산은 유지됩니다. 기본 선택지 자체는 삭제할 수 없습니다.
저장값과 개별 CSV 칼럼명은 각각 사용자가 직접 편집합니다. **양식 적용 및 저장 → CSV 다시 내보내기**를 하면 기존 사고 전체에 변경 사항을 반영하며 사고별 재입력이 필요하지 않습니다. 저장값이 중복되거나 다른 선택지의 이전 저장값과 겹치면 적용을 막습니다. 현재 양식은 버전 5이며, 구버전 앱은 읽을 수 없습니다.
장애물(보행자)과 충돌 대상의 기본 선택지는 기존 ‘어른’을 유지합니다. 기본 저장값은 각각 `어른`, `pedestrian.adult`이며, 기본 개별 CSV 칼럼은 `obstacle_adult`입니다. 이전 수정본이 ‘어른, 청소년’과 `obstacle_adult,youth`로 자동 변경해 저장한 기본 양식도 열 때 복구하며 기존 선택을 유지합니다. 현재 버전에서 사용자가 직접 편집해 저장한 값은 재실행해도 유지합니다.
기존 JSON의 `schema_version: 1`·`2`를 모두 읽어 이전합니다. 새 SQLite DB에는 저장소 버전과 양식 버전을 별도로 보관합니다. JSON 전용 구버전 앱에서는 새 DB를 읽을 수 없습니다.

작업 폴더의 `investigations.db`에 사고별 조사 값, 표시 순서, 영상 경로, 영상별 타임라인 마커·회전 각도(0°/90°/180°/270°), draft/completed 상태를 저장합니다. 원본 영상은 DB에 복사하지 않습니다. 입력/마커 변경 시 해당 목록 행만 갱신하고, 저장 시 변경한 사고만 트랜잭션으로 반영합니다. 조사 양식 변경은 호환성 검증 때문에 전체 사고를 확인합니다.

기존 `investigations.json`이 있으면 첫 열기에서 임시 DB로 변환하고 무결성·내용을 검증한 뒤 활성화합니다. 원본 JSON은 수정·삭제하지 않으며 이후 저장은 DB에만 반영합니다. 이전 실패 시 원본을 보존하고 오류를 표시합니다. DB가 이미 존재하면 JSON보다 우선하며, DB 오류 시 오래된 JSON으로 자동 되돌아가지 않습니다. 구버전 앱으로 같은 폴더를 계속 편집하면 JSON과 DB 내용이 달라지므로 함께 사용하지 마세요.

저장·불러오기·CSV 내보내기·백업의 디스크 작업은 별도 스레드에서 순차 처리합니다. 임시저장 중 조사 입력은 계속할 수 있으며, 저장 요청 이후의 추가 수정은 미저장으로 남겨 다음 저장에 반영합니다. 완료는 검증과 저장이 모두 성공한 후 화면에 반영하며 실패 시 미완료 상태를 유지합니다.

**파일 → 조사 데이터 백업…**으로 실행 중에도 일관된 단일 `.db` 백업을 만들 수 있습니다. 복원하려면 앱을 닫고 백업을 새 로컬 폴더에 `investigations.db`라는 이름으로 복사한 뒤 그 폴더를 엽니다. 영상 경로는 별도로 유지해야 합니다. 실행 중 생길 수 있는 `-wal`·`-shm` 파일은 임의 삭제하지 말고, DB 파일만 탐색기에서 복사하는 대신 앱의 백업 메뉴를 사용하세요. 작업 DB는 로컬 디스크에서 단독 사용하며 NAS/동기화 폴더에서의 공동 편집은 지원하지 않습니다.

성능·오류 진단 로그는 기본 `%LOCALAPPDATA%/AVAT/logs`의 `avat.log`와 `avat-crash.log`에 남습니다. 작업 시간·건수·프로세스 메모리와 오류 발생 위치를 기록하며 조사 입력값은 기록하지 않습니다. 로그는 크기 제한과 회전을 적용합니다. 강제 종료의 원인은 로그로 별도 확인해야 하며 모든 종료 상황에서 로그 기록이 보장되지는 않습니다.

### 병렬 디코더 격리와 타임라인 응답

기본 재생은 FFmpeg 자동 병렬 디코딩으로 동작하며, 캡처의 열기·탐색·읽기·해제는 전용 자식 프로세스 하나가 순차 처리합니다. UI 스레드는 프레임 복원 작업을 기다리지 않습니다. 명령은 작은 JSON 메시지로, 영상은 단일 RGB 공유 메모리 버퍼로 전달합니다. 최초 영상 열기만 성공/실패와 메타데이터를 확정하기 위해 제한 시간 내 대기합니다.

탐색 요청은 진행 중 한 건과 최신 대기 한 건만 유지합니다. 드래그 중 지난 대기 위치는 최신 위치로 교체하고, 이미 시작한 디코딩을 강제로 취소하지 않습니다. 손잡이·시각·프레임 입력은 요청 위치를 즉시 표시하며 이전 프레임 결과가 와도 되돌아가지 않습니다. 마커는 요청 위치가 아니라 실제 표시된 프레임에 지정합니다. 최근 프레임은 64MiB 이내의 바이트 제한 캐시에 보관하고, 영상 전환 시 비웁니다. 캐시의 표시 위치와 디코더의 실제 커서는 별도로 관리합니다.

네이티브 디코더가 비정상 종료되거나 응답을 멈추면 조사 입력과 마지막 화면을 보존하고 디코더만 제한적으로 재시작합니다. 첫 종료에는 병렬 모드를 재시도하고, 같은 영상에서 반복되면 해당 영상만 단일 스레드 안전 모드로 전환하며 추가 실패 시 자동 복구를 중단합니다. 안전 모드 기록은 현재 앱 실행 동안만 유지합니다. 영상 전환·닫기 후의 과거 결과는 무시하며, 종료 시 자식 프로세스와 공유 메모리를 정리합니다. 추가 패키지는 필요하지 않습니다. 통계 메타데이터 조회용 짧은 캡처는 기존 단일 스레드 정책을 유지합니다.

연속 1프레임 전진은 바로 다음 프레임을 읽어 불필요한 `CAP_PROP_POS_FRAMES` 탐색을 줄입니다. 뒤로 이동하거나 다른 위치로 점프할 때는 기존처럼 탐색합니다. 탐색·읽기 실패 시 일시정지하고 내부 위치를 무효화하며, 재개 시 마지막 표시 프레임 다음 위치로 재정렬합니다. 종료 시에는 정상 창 닫기뿐 아니라 이벤트 루프 종료 경로에서도 디코더를 정리합니다.

현재 버전의 Qt 오디오 디코더와 OpenCV 디코더를 구분해 시험하려면 실행 전에 다음과 같이 설정합니다. 음소거가 아니라 QMediaPlayer 자체를 생성하지 않으며 원본 영상은 바꾸지 않습니다. 설정하지 않은 기본 실행에서는 소리가 재생됩니다.

Windows의 Qt FFmpeg 로그는 `ERROR` 이상만 출력합니다. `stream 0, timescale not set` 등을 포함한 네이티브 경고는 터미널에 표시하지 않지만 실제 오류·치명적 오류와 다른 Qt 경고는 유지합니다. 표준 오류 스트림을 가로채거나 FFmpeg 스레드에서 Python 로그 콜백을 실행하지 않으며 영상 파일과 재생 설정은 바꾸지 않습니다.

```powershell
$env:AVAT_DISABLE_AUDIO = "1"
python main.py
```

오디오를 다시 사용하려면 다음 실행 전에 `$env:AVAT_DISABLE_AUDIO = "0"`으로 설정하거나 환경변수를 해제합니다. `936c18b`(2026-09-15, UI Update)에는 Qt 오디오가 없으므로 이 설정은 필요하지 않습니다. 해당 구버전용 최소 백포트 패치는 로컬 개발 자료 `local_dev/patches/avat-936c18b-single-thread.patch`로 관리하며 배포 저장소에는 포함하지 않습니다. 그 패치는 기본 `capture_factory`만 바꾸며 사용자 지정 팩토리와 UI는 유지합니다.

`async_lock` assert는 FFmpeg 프레임 스레드의 내부 불변식 실패입니다. 프로세스 분리는 OpenCV 디코더의 종료를 앱 전체에서 격리하는 조치이지 FFmpeg 내부 오류 자체를 수정하는 것은 아닙니다. Qt 오디오 디코더는 부모 프로세스에 남아 있으므로 모든 종류의 네이티브 오류를 격리한다는 뜻도 아닙니다. 오류는 상태 표시줄과 진단 로그에 남기며, 동일 증상이 남으면 원본 문제 영상·재현 조작·진단 로그로 추가 확인해야 합니다.

다음 조건을 모두 만족해야 완료할 수 있습니다.

- 고정 식별 정보와 일반 필수 질문 입력
- 장소는 일반장소·특수장소·기타 텍스트 중 하나 이상 입력
- 장애물 `유`이면 객체 종류와 거동 상태 입력, 차량 장애물이 있으면 대면 상태 입력
- 피해 `확인 가능`이면 경상·중상·사망·물피 수치를 모두 입력 (`0`도 유효)
- 경상부상급수(12~14급)와 중상부상급수(1~11급)를 각각 쉼표로 입력하면 목록을 오름차순 정렬하고 해당 인원수를 자동 집계하며, 각 목록의 가장 낮은 급수를 경상·중상대표부상급수로 분리해 표시
- 날짜와 시간의 실제 형식 및 날짜-요일 일치
- 각 영상에서 트리거가 충돌 프레임보다 늦지 않음

완료한 사고를 다시 수정하면 안전을 위해 draft 상태로 돌아갑니다.

### 배포본에서 JSON 자동 이전 기능 제거

이전 완료 후 자동 이전 코드를 제외하려면 다음 두 단계만 수행합니다.

1. `investigator/storage.py`의 `_migrate_legacy()` 안에서 `from investigator.legacy_migration import migrate_legacy as migrator` 한 줄을 주석 처리합니다.
2. `investigator/legacy_migration.py` 파일을 삭제합니다.

나머지 저장소 함수는 유지합니다. 기존 DB 읽기·저장·백업 및 빈 폴더의 새 DB 생성은 정상 작동합니다. JSON만 있는 폴더는 이전 필요 안내와 함께 열기·저장·백업을 중단하여 기존 자료를 보호합니다. 기본 소스에서는 자동 이전이 활성화되어 있습니다.

## CSV 규칙

CSV 저장 위치를 선택하면 **데이터 명세서(94개 항목)도 함께 내보내기** 체크박스가 표시됩니다. 기본값은 선택이며, 해제하면 CSV만 저장합니다. 선택 시 기본 열 이름 변경을 반영한 명세서를 같은 폴더의 `<CSV 파일명>_데이터명세서.xlsx`로 저장합니다. 명세서는 기본 94개 열을 설명하며, 사용자 정의 양식으로 추가한 열은 포함하지 않습니다. 같은 이름의 명세서가 있으면 옵션 창에서 덮어쓰기를 안내합니다.

- 요청서에 적힌 칼럼명은 오탈자와 대소문자까지 그대로 유지합니다. 예: `vehicle_milege`, `obstacle_Existence`, `incident_damage_Unknown`, `Lighting/Environmental_Condition`.
- 화면에서는 사고일자를 먼저 표시하지만 CSV 칼럼 순서는 기존 계약인 `incident_day`, `incident_date`를 유지합니다.
- 옵션별 boolean 칼럼은 선택된 값만 `1`로 기록하고, 미선택·미입력·비적용 값은 `null`로 기록합니다. 사용자가 명시적으로 입력하거나 선택한 실제 값 `0`은 유지합니다.
- 한 칼럼에 들어가는 다중 선택은 스키마 순서대로 `|`로 연결합니다.
- `collision_target`은 요청서의 선택값 그대로 `승용|어른`처럼 내보냅니다.
- `active_video_file`, `trigger_frame`, `collision_frames`는 현재 선택 영상 기준이며, 모든 영상의 마커는 `video_markers` JSON에도 함께 보존합니다. 호환성을 위해 `collision_frames` 이름은 유지하지만 영상별 값은 최대 1개이며, 기존 다중 값은 가장 이른 충돌 시점 하나로 정규화합니다.
- 영상이나 마커가 지정되지 않은 워크플로 메타데이터 셀도 `null`로 기록하며, 실제 값 `0`은 그대로 보존합니다.
- 자유 텍스트가 스프레드시트 수식 문자로 시작하면 작은따옴표를 붙여 수식 실행을 방지합니다.
- 비고 탭의 사고 추가정보는 `remarks` 칼럼에 줄바꿈을 포함한 텍스트로 기록합니다.
- 요청서가 “기존 `site_*` 칼럼”의 정확한 이름을 제공하지 않아, 현 버전은 [스키마 코드](investigator/schema.py)의 중앙 매핑을 사용합니다. 실제 기존 데이터셋 헤더가 제공되면 `SITE_CHOICES`만 교체하면 됩니다. 상세 개발 문서는 `local_dev/docs/CSV_SCHEMA.md`에 로컬 보관합니다.

## 검증

테스트와 개발 도구는 Git에서 제외되는 `local_dev/`에 있습니다. 해당 폴더가 있는 개발 환경에서 프로젝트 루트를 기준으로 실행합니다. 새로 GitHub에서 내려받은 앱 소스에는 로컬 테스트가 포함되지 않습니다.

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
pytest -q
ruff check investigator main.py
```

## 로컬 개발 자료 관리

앱 실행에 필요한 코드는 `investigator/`, 번들 자산은 `investigator/assets/`에 둡니다. 테스트·실험 스크립트·샘플 CSV/DB·HTML 시안·비교 보고서·패치·개발 문서는 모두 `local_dev/` 아래에서 관리합니다. 이 폴더는 `.gitignore`로 통째로 제외하므로 새 자료마다 제외 규칙을 추가할 필요가 없습니다. 로컬 전용 자료는 GitHub에 백업되지 않으므로 별도로 보관해야 합니다.

```text
local_dev/                 # Git 제외
├── tests/                # 테스트와 저장 성능 측정
├── tools/                # 샘플 생성·탐색 성능 측정 도구
├── samples/              # 샘플 CSV 및 샘플 작업 DB
├── mockups/              # HTML 시안과 관련 JS
├── reports/              # 측정 결과 JSON·비교 HTML
├── patches/              # 실험·구버전용 패치
├── docs/                 # 개발 분석·스키마 문서
├── references/           # 참고용 명세서 원본
├── backups/              # 개발 샘플 백업
├── requirements-dev.txt
└── 샘플 통계 열기.cmd
```

샘플 실행은 `local_dev/샘플 통계 열기.cmd`, 개발 의존성 설치는 `python -m pip install -r local_dev/requirements-dev.txt`를 사용합니다. 앱의 CSV 내보내기에 쓰이는 `investigator/assets/AVAT 데이터 명세서.xlsx`는 참고용 복사본과 달리 배포에 포함합니다. 글꼴·아이콘 라이선스도 함께 유지합니다.
