# Accident Video Analysis Tool (AVAT)

사고 영상을 프레임 단위로 보면서 조사 항목을 입력하고, 결과를 CSV·Word 보고서·통계로 정리하는 Windows 프로그램입니다.

## 주요 기능

- 13자리 사고번호 파일명으로 영상을 사고별 자동 분류, 새로 넣은 영상 자동 감지
- 영상 폴더(탭) → 사고 → 영상 목록, 검색·사고번호 정렬
- 재생·일시정지, 1/10프레임·1초 단위 이동, 프레임 번호 직접 이동, 화면 회전, 영상 소리 재생
- 영상마다 트리거(T)·충돌(C) 시점 지정
- 속도 기준 지점과 거리로 구간 평균 속도와 트리거 시점 속도 추정
- Grounding DINO 객체 검출과 트리거·충돌 관여 객체 라벨링
- 9개 탭의 조사 항목 입력, 날짜·요일·숫자 검증, 임시저장·완료 관리
- 조사 항목(양식) 편집
- 조사 결과 CSV·속도 분석 CSV·데이터 명세서(xlsx) 내보내기
- 사고별 Word 사고 분석 보고서(.docx) 생성
- 통계 분석: 개요·항목 분석·교차 분석·영상 지표·데이터 품질
- 최신 백업 1개 자동 유지, 백업 불러오기, 재설치 후 자동 복원

## 설치와 실행

배포본의 `01_EXE` 폴더에는 실행에 필요한 Python, 모든 라이브러리, GPU 연산용 CUDA 파일, 객체 검출 모델(Grounding DINO Base)이 함께 들어 있습니다. 인터넷 연결이나 별도 설치 없이 실행합니다.

1. `01_EXE` 폴더 안의 내용 전체를 zip 하나로 묶어 대상 PC로 옮깁니다.
2. 대상 PC 로컬 디스크의 짧은 경로(예: `D:\AVAT`)에 압축을 풉니다.
   바탕화면·다운로드처럼 깊은 경로에 풀면 Windows 경로 길이 제한(260자)에 걸려 압축 해제나 사고 삭제가 실패할 수 있습니다.
3. `systems\AVAT.exe`를 실행합니다. 필요하면 바탕화면에 바로 가기를 만들어 사용합니다.

### 미리 준비할 것

따로 내려받아 설치할 것은 없습니다. PC에 따라 다음만 확인합니다.

- **NVIDIA 그래픽 카드가 있는 PC**: 객체 검출에 GPU를 쓰려면 NVIDIA 그래픽 드라이버가 설치되어 있어야 합니다. 보통 이미 설치되어 있습니다. 드라이버가 없거나 오래되어 GPU를 쓰지 못하면 `systems\prerequisites`의 NVIDIA 드라이버 설치 파일로 설치·업데이트합니다.
- **NVIDIA 그래픽 카드가 없는 PC**: 그대로 실행됩니다. 객체 검출만 CPU로 실행되어 느립니다.
- 실행할 때 `MSVCP140.dll`, `VCRUNTIME140.dll` 같은 파일이 없다는 오류가 나오면 `systems\prerequisites\vc_redist.x64.exe`를 설치한 뒤 다시 실행합니다.

### 폴더 구성

`systems`의 상위 폴더(위 예에서는 `D:\AVAT`)가 작업 폴더입니다. 다른 작업 폴더는 **파일 → 작업 폴더 열기…**(`Ctrl+O`)로 엽니다.

```text
AVAT/
├── 01_사고동영상/          # 조사할 영상. 이 안의 폴더 하나가 화면 위쪽 탭 하나
│   ├── 2025년 1월/
│   ├── 2025년 2월/
│   └── 작업관리/
│       └── 작업관리.db     # 조사 데이터(프로그램이 관리, 직접 수정 금지)
├── 02_csv내보내기/         # CSV 내보내기 기본 위치
├── 03_Report내보내기/      # 사고 분석 보고서 기본 위치
├── 사용안내.txt            # 업데이트·백업·복원 절차
└── systems/
    ├── AVAT.exe            # 프로그램 실행
    ├── models/             # 객체 검출 모델
    ├── prerequisites/      # NVIDIA 드라이버·VC++ 런타임 설치 파일(필요할 때만)
    ├── 사용자데이터/       # 백업·삭제한 영상·설정·로그. 업데이트할 때 반드시 보존
    └── 그 밖의 프로그램 구성 파일
```

새 버전으로 업데이트하거나 다른 PC로 옮기는 절차는 배포본의 `사용안내.txt`에 있습니다.

## 기본 사용 흐름

1. `01_사고동영상` 아래 폴더(예: `2025년 1월`)에 영상을 넣고 실행합니다. 실행 중에 넣은 영상도 자동으로 목록에 추가되며, 바로 보이지 않으면 **목록 새로고침**(`Ctrl+R`)을 누릅니다.
2. 영상 파일 이름은 13자리 사고번호로 합니다. `2025010100001.mp4`, `2025010100001_1.mp4`, `2025010100001_2.mp4`처럼 같은 번호의 영상은 한 사고로 묶입니다. 규칙에 맞지 않는 이름의 영상은 사고를 선택한 뒤 **파일 → 현재 사고에 영상 추가…**(`Ctrl+Shift+O`)나 드래그앤드롭으로 연결합니다.
3. 위쪽 탭에서 영상 폴더를, 왼쪽 목록에서 사고와 영상을 고르고 재생하며 필요한 프레임을 찾습니다. 플레이어 위 회전 아이콘으로 영상을 90°씩 돌릴 수 있습니다.
4. **T 지정**, **충돌 지정**으로 트리거·충돌 시점을 기록합니다. 같은 프레임에서 다시 누르면 해제되고, 타임라인의 `T`·`C` 표시를 누르면 그 프레임으로 이동합니다.
5. 오른쪽 9개 탭의 조사 항목을 입력합니다. **비고** 탭에는 길이 제한 없이 추가 정보를 적습니다.
6. **임시저장**(`Ctrl+S`)하고, 입력 검증을 통과하면 **완료**를 누릅니다.
7. **다음**으로 현재 폴더의 다음 미완료 사고로 이동합니다.
8. 마지막에 **CSV 내보내기**(`Ctrl+E`)나 사고 분석 보고서를 만듭니다.

### 목록 사용 팁

- 영상 폴더 탭은 드래그해서 순서를 바꿀 수 있고, 탭 순서와 마지막으로 본 탭은 다시 실행해도 유지됩니다.
- 사고는 위·아래로 드래그해 표시 순서를 바꿀 수 있습니다. 검색창 오른쪽 버튼은 전체 사고를 사고번호 오름차순으로 정렬합니다.
- 화면의 프레임 번호는 1부터, CSV의 마커 프레임은 0부터 시작합니다.
- 폴더 이름을 바꾸거나 영상을 다른 하위 폴더로 옮겨 연결이 끊기면, 작업 폴더를 다시 열거나 목록 새로고침할 때 같은 파일 이름을 찾아 자동으로 다시 연결합니다. 같은 이름의 파일이 여러 개라 구분되지 않으면 연결하지 않으므로, 하위 폴더 구조를 유지해 구분되게 두세요. 파일 이름까지 바꾼 영상은 다시 연결할 수 없습니다.
- 탐색기에서 영상 파일을 지우거나 옮기는 것만으로는 조사 기록이 지워지지 않습니다. 사고·영상 삭제는 아래 기능을 사용합니다.

### 사고·영상 삭제

왼쪽 목록에서 사고나 영상을 선택하면 **사고 삭제** 또는 **영상 삭제** 버튼이 나타납니다.

- **사고 삭제**는 사고의 조사 내용과 모든 영상 연결을, **영상 삭제**는 선택한 영상의 연결과 그 영상의 T·C·속도 지점·회전·검출 결과만 지웁니다.
- 영상 파일은 지우지 않고 `systems\사용자데이터\삭제사고\<날짜-시각-번호>\`로 옮기며, 같은 폴더의 `이동기록.json`에 원래 위치를 기록합니다.
- 삭제 직전에 최신 백업(`systems\사용자데이터\백업\작업관리_백업.db`)을 갱신합니다.
- 삭제를 되돌리는 메뉴는 없습니다. 되돌려야 하면 **파일 → 조사 데이터 불러오기…**로 백업을 불러오고 영상을 원래 위치로 옮깁니다.
- 영상이 없는 빈 작업 폴더는 사고 0건으로 시작하며, 사고를 직접 만드는 메뉴는 없습니다. 사고번호 이름의 영상을 넣으면 사고가 생깁니다.

## 트리거 시점 속도 추정

플레이어 아래 **속도 지점** 또는 `M`으로 현재 프레임에 기준 지점을 추가합니다. 차량이 도로의 기준물을 지나는 순간을 골라 **같은 차량 기준점**으로 측정하세요. 같은 프레임에서 다시 누르면 해제됩니다.

1. 첫 지점은 시작점입니다. 두 번째 지점부터 **이전 지점부터 거리(m)**에 실제 기준물 사이 거리를 입력합니다. 새 지점에는 직전 거리가 복사되므로 실제 거리와 맞는지 확인하세요.
2. 각 구간의 평균 속도는 `거리 ÷ (프레임 차 / 실제 FPS) × 3.6`(km/h)으로 표시합니다.
3. T를 지정하면 **T가 들어 있는 두 지점**(T 바로 앞 지점과 T 이후 첫 지점) 사이의 평균 속도를 T 시점 속도로 계산합니다. T가 지점과 같은 프레임이면 그 지점에서 끝나는 앞 구간을, T가 첫 지점이면 첫 구간을 씁니다.
4. T 앞뒤에 지점이 없거나 그 구간의 거리가 비어 있으면 계산하지 않고, 무엇이 필요한지 안내합니다.
5. 그래프에는 구간 평균, T 시점 속도, 속도 구분 경계가 표시됩니다. 표·그래프의 지점을 누르면 그 프레임으로 이동합니다.
6. **차량 속도에 적용**을 눌렀을 때만 트리거 탭의 속도 구분에 반영합니다.

지점을 여러 개 찍으면 구간별 속도 변화를 볼 수 있지만, T 시점 속도에는 항상 T가 들어 있는 두 지점만 씁니다. 영상의 실제 FPS를 확인할 수 없으면 속도를 계산하지 않습니다. 가변 FPS 영상에서는 정확도가 떨어질 수 있으며, 표시 범위는 각 지점 ±0.5프레임 배치 민감도일 뿐 신뢰구간이나 감정 결과가 아닙니다. 측정 지점과 거리는 영상별로 저장되어 다시 실행해도 유지됩니다.

## 객체 검출과 관여 객체 라벨링

영상 전체가 아니라 필요한 구간만 검출합니다. 플레이어 아래 검출 아이콘(▣)으로 **객체 검출 · 라벨링** 패널을 엽니다.

1. **분석 구간**의 시작·끝 프레임을 입력하거나, 현재 프레임을 시작·끝으로 지정하거나, **T~C**를 누릅니다. 타임라인에서 `Shift`+드래그해도 구간이 선택됩니다. **간격**은 몇 프레임마다 검출할지 정합니다.
2. **검출 실행**을 누릅니다. 차량·이륜·PM·자전거·보행자와 시설물·건물·동물·낙하물 등 21개 분류를 찾으며, 결과는 자동으로 저장됩니다. 취소하거나 실패하면 기존 결과를 유지합니다.
3. 프레임 사이의 같은 객체는 하나의 ID(예: 차량 `V001`, 보행자 `P001`)로 묶습니다. 직접 그린 객체는 `U001`부터입니다.
4. 표나 영상 위 박스를 눌러 객체를 선택하고 **세분류**(승용·화물·어른·어린이 등)를 고릅니다. **동일 ID 전체 프레임에 적용**을 해제하면 현재 프레임만 바뀝니다. **확인**으로 검수 완료를 표시합니다.
5. **사각형 그리기**로 박스를 직접 추가하고, **객체 삭제**로 선택 객체를 지웁니다. 박스 편집은 `Ctrl+Z`로 실행 취소, `Ctrl+Y`로 다시 실행합니다.
6. **표시 신뢰도 ≥**로 신뢰도가 낮은 박스를 숨길 수 있습니다(기본 0.50). 숨긴 박스는 지워지지 않습니다.
7. **객체 탭에 반영 / 충돌 탭에 반영**을 눌러야만 조사 항목에 들어갑니다. 검출만으로 조사 값이 바뀌지 않으며, 세분류가 정해지지 않았거나 섞인 객체가 있으면 반영하지 않습니다.

검출은 보조 수단이므로 결과는 반드시 사람이 확인하세요. 연석·볼라드·과속방지턱 같은 작은 시설물과 화단·흙더미·낙하물은 놓치거나 잘못 찾는 경우가 많습니다. 검출 원본 결과는 CSV·보고서·통계에 들어가지 않고, 조사 탭에 반영한 값만 들어갑니다.

검출 실행 값(임계값·정밀도 등)은 기본값으로 고정되어 있어 따로 설정할 것이 없습니다. GPU가 있으면 GPU로, 없으면 CPU로 실행합니다.

## 통계 분석

위쪽 **조사 / 통계** 전환으로 통계 화면을 엽니다. 기본 집계 대상은 **완료** 사고이며, 임시저장 사고 포함·사고일자 기간·조사 항목 조건을 추가할 수 있습니다. 통계 화면을 여는 것만으로 조사 데이터가 바뀌지는 않습니다.

- **조건 추가**: 항목을 고르고 값을 체크합니다. 한 조건 안의 값끼리는 OR, 조건끼리는 기본 AND입니다. 조건 칩을 2개 이상 체크하고 **OR로 묶기**를 누르면 그 조건들만 OR로 묶습니다. 수치 항목은 `최소(이상) ~ 최대(미만)`으로 범위를 지정하고, **제외**로 해당 값이 아닌 사고를 고를 수 있습니다.
- **개요**: 사고 수, 인명피해 사고 수, 평균 트리거→충돌 시간, 필수 미입력 사고 수와 고정한 항목의 분포
- **항목 분석**: 항목별 건수·비율 막대, 파이, 표. 수치 항목은 구간 분포와 평균·중앙값·사분위수
- **교차 분석**: 두 항목의 관계를 봅니다.
  - 범주×범주: **히트맵** 또는 **100% 누적 막대**(행마다 전체를 100%로 놓고 구성비를 쌓은 막대)
  - 범주×수치: **상자수염**
  - 수치×수치: 산점도와 추세선
  - **양방향 막대**: 가운데 항목의 분포를 두 그룹으로 나눠 왼쪽(파란색)·오른쪽(주황색)에 나란히 비교합니다. 좌우 그룹 항목에서 왼쪽·오른쪽 그룹에 넣을 값을 각각 고르며, 여러 값을 고르면 하나라도 해당하는 사고를 합칩니다. 같은 값을 양쪽에 고를 수 없고, 두 그룹 어디에도 속하지 않는 사고는 제외합니다. **그룹 내 비율**(기본) 또는 **건수**로 볼 수 있으며, 차이는 왼쪽 비율에서 오른쪽 비율을 뺀 값(%p)입니다.
  - **읽는 법**에 참고용 통계 검정 결과가 함께 나옵니다. 검정과 추세선은 인과관계를 뜻하지 않습니다.
- **영상 지표**: 영상의 T·C 지정률과 트리거→충돌 시간(`(충돌 프레임 − 트리거 프레임) / 실제 FPS`)
- **데이터 품질**: 상태와 관계없이 전체 사고의 필수 항목 입력률·미입력·오류. 문제 사고를 누르면 조사 화면의 해당 항목으로 이동합니다.

그래프의 막대나 표의 칸을 누르면 오른쪽에 해당 사고 목록이 나옵니다. 사고를 눌러 조사 화면으로 이동하거나 **이 조건을 필터로 고정**할 수 있습니다. 다중 선택 항목은 한 사고가 여러 값에 들어가므로 비율 합계가 100%를 넘을 수 있습니다.

**내보내기**로 현재 그래프·표 이미지(PNG), 집계 표(CSV), 개요 요약(PDF)을 저장합니다.

## 사고 분석 보고서 내보내기

왼쪽 **사고 분석 보고서 내보내기** 또는 **파일 → 사고 분석 보고서 내보내기…**를 누릅니다.

1. 보고서로 만들 사고를 체크합니다. 검색, 전체 선택·해제를 지원하며 작성 중인 사고도 내보낼 수 있습니다.
2. **조건으로 사고 선택**에서 완료 상태·사고일자·조사 항목 조건을 지정하면 일치하는 사고만 자동으로 체크합니다.
3. 저장 폴더를 고릅니다. 기본 위치는 `03_Report내보내기`입니다.

사고마다 `SAMSUNG-20200113_001_사고분석보고서.docx`처럼 보고서용 사고번호로 파일을 만들고, 같은 이름이 있으면 `_2`, `_3`을 붙여 기존 파일을 보존합니다. 미입력 텍스트는 `-`로, 선택 항목은 체크박스로 표시합니다. Word가 설치되지 않은 PC에서도 만들 수 있습니다.

## 조사 항목 편집

**설정 → 조사 항목 편집…**에서 현재 작업 폴더의 조사 양식을 바꿉니다.

- 탭·항목의 이름, CSV 칼럼명, 입력 방식(드롭다운·숫자·텍스트·다중 선택), 필수 여부, 선택지, 기본값을 편집합니다.
- **탭 추가**·**항목 추가**로 양식을 늘리고, **▲ / ▼**로 순서를 바꿉니다. 탭마다 1열·2열 배치를 고를 수 있습니다.
- 직접 추가한 항목·탭만 삭제할 수 있습니다. 기본 항목은 삭제할 수 없습니다.
- **양식 적용 및 저장**을 눌러야 반영됩니다. 기존 사고에 입력한 값은 보존하며, 기본값은 이후 새로 생기는 사고에만 적용합니다.
- **초기 설정 복원**으로 기본 양식으로 되돌릴 수 있습니다(추가한 항목과 입력 값은 유지).
- 양식은 작업 폴더의 조사 데이터에 함께 저장되며 다른 작업 폴더에는 영향을 주지 않습니다.

## 완료 조건

다음을 모두 만족해야 **완료**할 수 있습니다. 완료한 사고를 다시 수정하면 작성 중 상태로 돌아갑니다.

- 식별 정보와 필수 질문 입력
- 장소는 일반장소·특수장소·기타 입력 중 하나 이상
- 장애물 `유`이면 객체 종류와 거동 상태, 차량 장애물이면 대면 상태까지 입력
- 피해 `확인 가능`이면 경상·중상·사망·물피 수치를 모두 입력(`0`도 유효)
- 경상부상급수(12\~14급)와 중상부상급수(1\~11급)는 쉼표로 입력하며, 인원수와 대표부상급수는 자동 계산
- 날짜·시간이 실제 있는 값이고 요일이 날짜와 일치
- 각 영상에서 트리거가 충돌보다 늦지 않음

## CSV 내보내기

**CSV 내보내기**(`Ctrl+E`)는 기본으로 `02_csv내보내기`에 다음 파일을 함께 만듭니다.

- `<파일명>.csv`: 사고 1건당 1행의 조사 결과
- `<파일명>_속도분석.csv`: 영상별 T·C·속도 지점 기록
- `<파일명>_데이터명세서.xlsx`: 칼럼 설명(체크를 해제하면 만들지 않음)

조사 결과 CSV의 규칙은 다음과 같습니다.

- 모든 파일은 UTF-8 BOM 형식이며, 빈 값은 `null`로 기록합니다. 실제로 입력한 `0`은 그대로 둡니다.
- 칼럼 순서는 조사 양식의 탭 → 항목 → 선택지 순서를 따릅니다. 맨 앞의 `report_accident_number`와 이어지는 기본 정보 7개 칼럼만 위치가 고정입니다.
- 선택지별 칼럼은 선택한 값만 `1`, 나머지는 `null`입니다. 한 칼럼에 들어가는 다중 선택은 `|`로 연결합니다(예: `승용|어른`).
- 칼럼명은 요청서의 표기를 그대로 따릅니다(예: `vehicle_milege`, `obstacle_Existence`).
- `report_accident_number`는 보고서용 사고번호입니다. 사고번호 앞 8자리 날짜별로 `20200113_001`, `20200113_002`처럼 매기며, 같은 날짜의 사고가 늘거나 줄면 다시 계산됩니다. 원래 사고번호는 `accident_classification`에 그대로 있습니다.
- `active_video_file`, `trigger_frame`, `collision_frames`는 현재 선택한 영상 기준이며, 모든 영상의 마커는 `video_markers`에 함께 기록합니다.
- 비고는 `remarks` 칼럼에 줄바꿈을 포함해 기록합니다. `=`, `+`, `-`, `@`로 시작하는 텍스트에는 엑셀 수식으로 실행되지 않도록 작은따옴표를 붙입니다.

### 속도 분석 CSV

사고에 연결된 모든 영상의 T·C·속도 지점마다 한 행을 기록합니다.

| 칼럼 | 의미 |
| --- | --- |
| `case_id`, `accident_classification`, `report_accident_number` | 사고 표시 ID, 원래 사고번호, 보고서용 사고번호 |
| `video_file`, `video_name` | 영상 경로, 파일명 |
| `event_type`, `point_index` | `trigger` / `collision` / `speed_point`, 속도 지점 번호(1부터) |
| `frame_index`, `display_frame` | 내부 프레임(0부터), 화면에 표시되는 프레임(1부터) |
| `time_seconds`, `timecode`, `fps` | 영상 시작 기준 초, `HH:MM:SS.mmm` 시각, 실제 영상 FPS |
| `previous_point_frame_index`, `previous_point_time_seconds` | 바로 이전 속도 지점의 내부 프레임·초 |
| `distance_from_previous_m` | 이전 속도 지점부터 입력한 거리(m) |
| `segment_speed_kph` | 해당 구간의 평균 속도(km/h) |
| `trigger_speed_estimate_kph` | T 행에만 기록하는 트리거 시점 추정 속도(km/h) |
| `estimate_method`, `estimate_warnings` | 계산 방식, `거리 미입력`·`FPS 미확인` 등 짧은 경고 |
| `missing_distance_points` | 거리가 입력되지 않은 속도 지점 번호 목록(예: `[2, 3]`) |

첫 속도 지점과 계산할 수 없는 값은 `null`입니다. FPS를 임의로 가정하지 않습니다.

## 백업과 불러오기

- 백업 파일은 작업 폴더당 하나(`systems\사용자데이터\백업\작업관리_백업.db`)만 유지하며, 사고·영상 삭제 직전, 영상 경로 자동 복구 직전, 프로그램 종료 때 자동으로 갱신됩니다.
- **파일 → 조사 데이터 백업…**으로 원하는 위치(외장 저장장치 등)에 따로 사본을 만들 수 있습니다. 정기적으로 사본을 보관하세요. 백업에는 조사 데이터만 들어가고 영상은 들어가지 않습니다.
- **파일 → 조사 데이터 불러오기…**로 백업 파일이나 다른 PC의 `작업관리.db`를 골라 현재 조사 데이터를 바꿉니다. 바꾸기 전 데이터는 위 백업 파일로 저장되고, 고른 파일은 바뀌지 않습니다.
- 다시 설치한 뒤 조사 데이터가 없으면 `작업관리_백업.db`에서 자동으로 복원합니다.
- 조사 데이터는 로컬 디스크에서 한 PC가 단독으로 사용합니다. 같은 작업 폴더를 두 창에서 동시에 열 수 없습니다.

자세한 업데이트·복원 절차는 `사용안내.txt`를 참고하세요.

## 문제 해결

- **"다른 AVAT 창에서 이 작업 폴더를 사용 중입니다"**: 열려 있는 다른 AVAT 창을 닫고 다시 실행합니다. 비정상 종료로 남았거나 다른 PC에서 복사돼 온 잠금은 자동으로 풀립니다. 창이 없는데도 계속 나오면 작업 관리자에서 남아 있는 `AVAT.exe`를 종료합니다.
- **"조사 데이터베이스를 읽을 수 없습니다"**: **파일 → 조사 데이터 불러오기…**로 백업을 고릅니다. 읽을 수 없던 기존 데이터는 `01_사고동영상\작업관리\작업관리_읽기오류_<날짜>.db`로 보존됩니다.
- **객체 검출이 느림**: NVIDIA 그래픽 카드가 없거나 드라이버 문제로 GPU를 쓰지 못하면 CPU로 실행되어 느립니다. 위 **미리 준비할 것**을 확인합니다.
- **문의할 때**: `systems\사용자데이터\logs\avat.log`를 함께 보내 주세요. 로그에는 사고번호·입력값·영상 파일명이 기록되지 않습니다.
