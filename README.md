# 사고 영상 조사 도구

사고별 영상을 프레임 단위로 검토하면서 조사 항목을 입력하고, 임시저장·완료 처리한 결과를 CSV로 내보내는 PySide6 데스크톱 앱입니다. 기존 `avat_ai/`의 OpenCV 재생 구조, 흰색·파란색 시각 체계, 번들 Material Symbols 아이콘을 참고해 새 프로젝트로 분리했습니다.

## 주요 기능

- 사고 목록과 사고별 복수 영상 관리
- OpenCV 기반 재생/일시정지, ±1/10프레임, ±5초 이동, 프레임 번호 직접 이동
- 영상마다 트리거 `T` 1개와 충돌 `C` 1개 타임라인 마커 지정·저장
- 식별 구분을 우측 상단에 고정하고 나머지 2~9번 항목을 8개 탭으로 제공
- 숫자·길이·실제 날짜/시간·요일 일치 검증
- 거리 수치에 따른 범위와 사고일자에 따른 요일 자동 입력
- 장애물 유무 및 피해 확인 가능 여부에 따른 조건부 입력
- 논리적 필수 질문 기준의 `미입력 N` 표시
- 원자적 JSON 임시저장, 완료 상태 관리, 다음 미완료 사고 이동
- 사고 1건당 1행의 UTF-8 BOM CSV 내보내기

## 설치 및 실행

Python 3.11~3.13 환경을 권장합니다.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python main.py
```

작업 폴더를 지정해 실행할 수도 있습니다.

```powershell
python main.py --workspace "D:\investigations"
```

지정하지 않으면 Windows 문서 폴더 아래 `사고영상조사`를 사용합니다. 앱의 **파일 → 작업 폴더 열기**에서도 변경할 수 있습니다.

## 기본 사용 흐름

1. 왼쪽의 **새 사고**를 눌러 기본 기관 `samsung`의 `SAMSUNG-001` 형식 사고를 만듭니다.
2. **영상 추가** 또는 영상 파일 드래그앤드롭으로 현재 사고에 영상을 연결합니다.
3. 중앙 영상 플레이어 아래 컨트롤이나 단축키로 필요한 프레임을 찾습니다.
4. **T 지정**, **충돌 지정**으로 조사 기준 시점을 기록합니다. 다른 프레임을 지정하면 기존 시점이 교체되고, 같은 프레임에서 다시 누르면 해당 마커가 해제됩니다. 타임라인의 `T` 또는 `C` 마크를 클릭하면 해당 프레임으로 이동하며, 마우스를 올리면 강조색·포인터 커서·프레임 안내가 표시됩니다.
5. 우측 식별 영역과 8개 탭의 조사 항목을 입력합니다.
6. 오른쪽 조사 패널 하단에서 **임시저장**, 검증을 통과한 뒤에는 **완료**를 누릅니다.
7. **다음**으로 다음 미완료 사고로 이동하고, 마지막에 **조사 결과 CSV 내보내기**를 사용합니다.

화면에 표시되는 프레임 번호는 사람이 읽기 쉬운 1부터 시작하고, JSON과 CSV의 마커 프레임은 영상 처리 호환을 위해 0부터 시작합니다.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 재생 / 일시정지 | `Space` |
| ±1프레임 | `←` / `→` |
| ±10프레임 | `Ctrl+←` / `Ctrl+→` |
| ±5초 | `J` / `L` |
| 임시저장 | `Ctrl+S` |

입력 필드에 포커스가 있을 때는 재생 단축키가 입력을 가로채지 않습니다.

## 저장 형식과 완료 기준

작업 폴더의 `investigations.json`에 스키마 버전, 사고별 조사 값, 영상 경로, 영상별 타임라인 마커, draft/completed 상태를 저장합니다. 임시 파일을 같은 폴더에 쓴 뒤 교체하므로 저장 도중 중단되어도 기존 정상 파일을 보존합니다.

다음 조건을 모두 만족해야 완료할 수 있습니다.

- 고정 식별 정보와 일반 필수 질문 입력
- 장소는 일반장소·특수장소·기타 텍스트 중 하나 이상 입력
- 장애물 `유`이면 객체 종류와 거동 상태 입력, 차량 장애물이 있으면 대면 상태 입력
- 피해 `확인 가능`이면 경상·중상·사망·물피 수치를 모두 입력 (`0`도 유효)
- 날짜와 시간의 실제 형식 및 날짜-요일 일치
- 각 영상에서 트리거가 충돌 프레임보다 늦지 않음

완료한 사고를 다시 수정하면 안전을 위해 draft 상태로 돌아갑니다.

## CSV 규칙

- 요청서에 적힌 칼럼명은 오탈자와 대소문자까지 그대로 유지합니다. 예: `vehicle_milege`, `obstacle_Existence`, `incident_damage_Unknown`, `Lighting/Environmental_Condition`.
- 개별 boolean 칼럼은 선택 `1`, 비선택 `0`, 미입력은 빈 값입니다.
- 한 칼럼에 들어가는 다중 선택은 스키마 순서대로 `|`로 연결합니다.
- `collision_target`은 요청서의 선택값 그대로 `승용|어른`처럼 내보냅니다.
- `active_video_file`, `trigger_frame`, `collision_frames`는 현재 선택 영상 기준이며, 모든 영상의 마커는 `video_markers` JSON에도 함께 보존합니다. 호환성을 위해 `collision_frames` 이름은 유지하지만 영상별 값은 최대 1개이며, 기존 다중 값은 가장 이른 충돌 시점 하나로 정규화합니다.
- 자유 텍스트가 스프레드시트 수식 문자로 시작하면 작은따옴표를 붙여 수식 실행을 방지합니다.
- 요청서가 “기존 `site_*` 칼럼”의 정확한 이름을 제공하지 않아, 현 버전은 [CSV 스키마 문서](docs/CSV_SCHEMA.md)에 적힌 중앙 매핑을 사용합니다. 실제 기존 데이터셋 헤더가 제공되면 `investigator/schema.py`의 `SITE_CHOICES`만 교체하면 됩니다.

## 프로젝트 구조

```text
investigator/
├── app.py                 # Qt 앱 초기화
├── main_window.py         # 전체 워크플로 연결
├── schema.py              # 필드·검증·CSV 단일 계약
├── models.py              # 사고 조사 모델
├── storage.py             # 원자적 JSON 저장과 CSV 내보내기
├── video_controller.py    # OpenCV 재생/탐색
├── theme.py               # 테마와 번들 아이콘/글꼴
└── widgets/               # 목록, 조사 폼, 영상, 타임라인
```
