# Accident Video Analysis Tool (AVAT)

사고별 영상을 프레임 단위로 검토하면서 조사 항목을 입력하고, 임시저장·완료 처리한 결과를 CSV로 내보내는 PySide6 데스크톱 앱입니다.

## 주요 기능

- 13자리 사고번호 파일명을 기준으로 폴더 영상을 사고별 자동 분류
- 사고 목록과 사고별 복수 영상 관리, 확인 절차가 있는 사고·영상 삭제
- 프로젝트 폴더별 독립 탭, 사이드바의 현재 프로젝트명 표시, 현재 탭/새 탭 열기 선택
- 프로젝트 폴더의 새 영상 자동 감지, 가져오기 시 작업 폴더로 복사 선택
- OpenCV 기반 재생/일시정지, 영상 소리 출력, ±1/10프레임, ±1초 이동, 프레임 번호 직접 이동
- 영상마다 트리거 `T` 1개와 충돌 `C` 1개 타임라인 마커 지정·저장
- 식별 구분을 우측 상단에 고정하고 조사 항목과 자유 텍스트 비고를 9개 탭으로 제공
- 사고 구분 번호 최대 13자리와 `20-24세`~`95-99세`의 5세 단위 운전 연령 선택
- 사고 당시 주행거리는 자리수 제한 없이 숫자로 입력
- 트리거 시점 사고 정보의 2열 입력 배치
- 숫자·길이·실제 날짜/시간·요일 일치 검증
- 거리 수치에 따른 범위와 사고일자(직접 입력·달력 선택)에 따른 요일 자동 입력
- 일요일부터 시작하는 달력과, 사고일자 아래의 회색 읽기 전용 사고요일 표시
- 장애물 유무 및 피해 확인 가능 여부에 따른 조건부 입력
- 논리적 필수 질문 기준의 `미입력 N` 표시
- SQLite 트랜잭션 기반 사고별 부분 저장, 완료 상태 관리, 다음 미완료 사고 이동
- 사고 1건당 1행의 UTF-8 BOM CSV 내보내기

## 설치 및 실행

Python 3.11~3.13 환경을 권장합니다.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python main.py
```

작업 폴더를 지정해 실행할 수도 있습니다.

```powershell
python main.py --workspace "D:\investigations"
```

지정하지 않으면 Windows 문서 폴더 아래 `사고영상조사`를 사용합니다. 앱의 **파일 → 프로젝트 폴더 열기**, 상단 **+**, 사이드바 폴더 아이콘 또는 `Ctrl+O`로 프로젝트 폴더를 열 수 있습니다. 폴더를 선택하면 **현재 탭으로 불러오기 / 새 탭에서 열기**를 선택하며 기본 선택은 새 탭입니다. 이미 열린 폴더를 선택하면 해당 탭으로 이동합니다.

각 프로젝트는 자신의 폴더에 있는 `investigations.db`를 사용합니다. 상단 프로젝트 탭을 누르면 사고 목록·조사 양식이 전환되고 사이드바 최상단에 현재 폴더명이 표시됩니다. 긴 이름은 줄임표로 표시하며 탭이나 폴더명에 마우스를 올리면 전체 경로를 확인할 수 있습니다. 현재 탭에서 다른 프로젝트를 열어도 이전 프로젝트의 저장 데이터는 해당 폴더에 보존됩니다.

탭 전환·현재 탭 교체·탭 닫기 전에 변경 사항을 저장하며 실패하면 동작을 취소합니다. 탭을 오갈 때 검색어·사고 목록 펼침/선택 상태·조사 탭·영상 프레임을 복원하고 영상은 일시정지 상태로 엽니다. 비활성 프로젝트의 영상 디코더는 닫습니다. 탭 구성은 현재 실행 중에 유지되며, 다음 실행에서는 지정한 프로젝트 하나로 시작합니다.

## 기본 사용 흐름

1. 프로젝트 폴더를 처음 열면 그 폴더 바로 아래의 영상을 자동으로 검색합니다. 다른 위치의 원본 영상은 **파일 → 현재 사고에 영상 추가**나 드래그앤드롭으로 추가합니다. 기관은 `samsung`으로, 파일명의 13자리 숫자는 사고 구분 번호로 자동 입력됩니다.
2. `1234567890123.mp4`, `1234567890123_1.mp4`, `1234567890123_2.mp4`처럼 같은 사고번호를 가진 영상은 한 사고에 묶이고, 기본 영상과 뒤쪽 번호 순서로 정렬됩니다. 파일 메뉴의 **현재 사고에 영상 추가**나 드래그앤드롭으로 개별 영상을 직접 연결할 수도 있습니다.
3. 왼쪽 사고 항목을 위·아래로 드래그하면 표시 순서가 바뀌며, 변경된 순서는 작업 DB에 저장됩니다.
4. 중앙 영상 플레이어 아래 컨트롤이나 단축키로 필요한 프레임을 찾습니다. 플레이어 상단의 회전 아이콘을 누를 때마다 현재 영상이 시계 방향으로 90°씩 회전하며, 0° → 90° → 180° → 270° 순서로 순환합니다.
5. **T 지정**, **충돌 지정**으로 조사 기준 시점을 기록합니다. 다른 프레임을 지정하면 기존 시점이 교체되고, 같은 프레임에서 다시 누르면 해당 마커가 해제됩니다. 타임라인의 `T` 또는 `C` 마크를 클릭하면 해당 프레임으로 이동하며, 마우스를 올리면 강조색·포인터 커서·프레임 안내가 표시됩니다.
6. 우측 식별 영역과 9개 탭의 조사 항목을 입력합니다. **비고** 탭에는 글자 수 제한 없이 사고 추가정보를 입력할 수 있습니다.
7. 오른쪽 조사 패널 하단에서 **임시저장**, 검증을 통과한 뒤에는 **완료**를 누릅니다.
8. **다음**으로 다음 미완료 사고로 이동하고, 마지막에 **조사 결과 CSV 내보내기**를 사용합니다.

왼쪽 목록에서 사고나 개별 영상을 선택하면 **사고 삭제** 또는 **영상 삭제** 버튼이 표시됩니다. 삭제 전 확인을 거치며, 영상을 목록에서 삭제해도 디스크의 원본 영상 파일은 삭제하지 않습니다. 삭제한 영상은 작업 폴더를 다시 열어도 자동 복원되지 않으며, **현재 사고에 영상 추가**를 명시적으로 사용하면 다시 연결할 수 있습니다.

빈 작업 폴더는 사고 `0건`으로 시작하며 `SAMSUNG-001`을 자동 생성하지 않습니다. **새 사고**를 눌렀을 때만 수동 입력용 사고를 만들고, 마지막 사고도 실제로 삭제할 수 있습니다. 이전 버전에서 `SAMSUNG-001`에 잘못 연결된 13자리 파일명 영상은 작업 폴더를 열 때 파일명의 사고번호로 자동 이관하며 영상별 마커도 함께 보존합니다.

화면에 표시되는 프레임 번호는 사람이 읽기 쉬운 1부터 시작하고, DB와 CSV의 마커 프레임은 영상 처리 호환을 위해 0부터 시작합니다.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 재생 / 일시정지 | `Space` |
| ±1프레임 | `←` / `→` |
| ±10프레임 | `Ctrl+←` / `Ctrl+→` |
| ±1초 | `J` / `L` |
| 임시저장 | `Ctrl+S` |

입력 필드에 포커스가 있을 때는 재생 단축키가 입력을 가로채지 않습니다.

영상에 음성 트랙이 있으면 시스템 기본 출력 장치로 소리를 재생합니다. 일시정지·탐색·영상 전환 시 소리도 함께 제어하며, 음성 트랙이 없는 영상은 무음으로 재생합니다. 재생바 드래그는 이동한 위치를 별도 대기 시간 없이 즉시 반영합니다. 일시정지 중에는 오디오 탐색을 반복하지 않고, 재생을 시작할 때 최종 위치에 맞춥니다. 영상 재생은 기존 OpenCV의 백엔드·스레드 자동 설정을 사용합니다.

오디오 백엔드의 초기화 안내와 영상 메타데이터 출력은 숨깁니다. 파일 시간 정보 경고나 디코딩 오류 등 경고·오류 로그는 유지합니다.

프로젝트 폴더의 자동 검색은 폴더 바로 아래에 있는 지원 영상 파일을 읽습니다. 이름이 `13자리 숫자` 또는 `13자리 숫자_1`, `_2` 형식이 아닌 영상은 건너뛰며, 같은 폴더를 다시 열어도 기존 사고와 영상은 중복 생성되지 않습니다.

열려 있는 프로젝트 폴더는 `QFileSystemWatcher`로 감시합니다. 폴더 바로 아래에 새 영상이 생기면 크기·수정 시간이 2초 동안 안정되고 읽을 수 있는지 확인한 뒤, 기존 13자리 사고번호 규칙에 따라 자동으로 추가·저장합니다. 하위 폴더는 감시하지 않으며, 파일 복사가 잠시 멈춘 경우에는 이 안정화 시간만으로 복사 완료를 확정할 수 없습니다. 기존 영상 파일을 삭제해도 조사 기록을 자동 삭제하지는 않습니다. 목록에서 직접 삭제한 영상·사고의 제외 설정은 자동 갱신에도 적용합니다.

현재 프로젝트의 자동 갱신은 수정한 목록 행과 새 사고만 반영하고 입력 중인 값·선택 사고·영상 재생 위치를 유지합니다. 다른 프로젝트 탭에서 새 영상이 감지되면 탭 이름에 `•`가 표시되고 해당 탭으로 이동할 때 반영합니다. 저장·복사·대화상자 처리 중에는 갱신을 보류하며, 저장 실패 시 입력값을 유지하고 잠시 후 다시 시도합니다.

**현재 사고에 영상 추가**, 영상 드래그앤드롭으로 가져올 때 나타나는 옵션에서 **작업 폴더로 복사**를 선택할 수 있습니다. 기본값은 선택하지 않은 연결형입니다. 선택하면 원본은 그대로 두고 현재 프로젝트 폴더에 파일을 복사한 뒤 복사본을 연결합니다. 개별 추가는 일반 파일명도 지원합니다. 같은 이름의 내용이 다른 파일은 순번을 붙이며, 13자리 사고번호는 유지합니다. 기존 파일과 내용이 같으면 해당 파일을 재사용합니다. 복사는 임시 파일에 완료한 뒤 최종 이름으로 반영하고, 복사·조사 데이터 저장 실패 시 이번에 생성한 복사본을 정리합니다. 복사 작업은 별도 작업 스레드에서 수행합니다.

## 저장 형식과 완료 기준

**설정 → 조사 항목 편집…** 또는 사고 조사 입력 제목 옆 편집 버튼에서 현재 작업 폴더의 양식을 변경할 수 있습니다.
왼쪽에서 탭·항목을 선택해 탭 제목/라벨, 항목 이름, CSV 칼럼명, 입력 방식, 필수 여부, 선택지와 기본값을 편집합니다.
**탭 추가**, **항목 추가**로 양식을 확장하고 **양식 적용 및 저장**을 누르면 즉시 화면에 반영됩니다. 취소하면 적용되지 않습니다.
왼쪽에서 탭 또는 항목을 선택하고 **▲ / ▼**로 순서를 변경할 수 있습니다. 항목은 해당 탭 안에서 이동하며, 상단 식별 구분 영역은 고정됩니다.
식별 구분의 기본 배치는 기관코드와 사고 구분 번호가 나란히 표시되는 2열입니다. 편집창의 식별 구분 → 항목 배치에서 1열/2열을 선택할 수도 있습니다.
**초기 설정 복원**은 `investigations.db`의 `initial_form_definition` 설정에 별도로 보관한 기본 양식의 이름·입력 방식·기본값·순서·배치를 불러옵니다. 복원 기준은 양식을 편집해도 변경되지 않습니다. 기존 작업 폴더에는 이 버전의 기본 양식을 초기값으로 추가합니다.
**초기 설정 복원**을 누르면 확인창이 표시되며 기본 선택은 ‘아니요’입니다. ‘예’를 선택하면 편집창에서 복원 결과를 확인할 수 있고, **양식 적용 및 저장**으로 확정합니다. 취소하면 편집 중인 내용도 그대로 유지합니다. 추가한 탭·항목·선택지와 조사 값 및 CSV 별칭은 유지합니다. 기존 조사 값이 초기 입력 방식과 맞지 않으면 일반 양식 편집과 동일하게 적용을 막고 해당 항목을 안내합니다.
탭의 **항목 배치**에서 1열(세로) 또는 2열(좌우)을 선택합니다. 2열은 목록 순서대로 왼쪽 → 오른쪽으로 배치하며, 항목별 **한 행 전체 너비 사용**으로 특정 항목만 전체 너비를 사용할 수 있습니다.
충돌 탭은 충돌대상 → 피해정도 확인불가를 전체 너비로 표시하고, 경상·중상 부상급수/대표급수/인원 및 사망·물적피해 항목을 좌우에 배치합니다. 순서·배치는 작업 폴더에 저장되며 재실행 시 복원됩니다. 화면 순서 변경은 CSV 칼럼 순서를 바꾸지 않습니다.
입력 방식은 드롭다운, 정수·소수, 한 줄·여러 줄 텍스트, 체크박스/다중 선택을 지원합니다. 선택지의 표시 이름과 저장값은 별개이며, 기본값은 저장값으로 입력합니다(다중 선택은 한 줄에 하나).

양식은 `investigations.db`의 `form_definition` 설정에 사고 데이터와 함께 저장되어 재실행 시 복원됩니다. 다른 작업 폴더에는 영향을 주지 않습니다.
기본값은 이후 생성하거나 가져오는 새 사고에만 적용하며 기존 사고나 사용자가 비운 값은 덮어쓰지 않습니다.
기존 값에 맞지 않는 입력 방식·선택지 변경은 적용되지 않습니다. 새 필수 조건 때문에 완료 조건을 충족하지 못하는 사고는 미완료로 전환되고 입력 내용은 유지됩니다.

호환성을 위해 내부 항목 식별자는 고정합니다. 항목 자체의 CSV 칼럼명 변경은 기존 별칭을 유지하며, 사용자 정의 항목은 뒤에 추가합니다. 선택지의 **개별 CSV 칼럼**을 변경하면 해당 위치의 헤더를 새 이름으로 교체하며 이전 이름의 칼럼을 중복 출력하지 않습니다.
빈 값은 기존과 같이 `null`로 출력합니다. 선택지의 저장값을 바꾸면 텍스트형 CSV에는 바꾼 저장값을 출력합니다. 기본 충돌 대상은 기존처럼 범주 접두어를 뺀 선택값을 `|`로 연결합니다. 개별 선택 여부 칼럼은 `1`/`null`을 유지합니다.
날짜·요일, 부상급수, 조건부 질문, 선택지별 CSV 분리 항목은 자동 계산에 필요한 입력 방식과 필수 규칙을 보호합니다. 선택지의 표시 이름·저장값·개별 CSV 칼럼은 편집할 수 있습니다. 저장값을 바꾸면 기존 조사 결과와 기본값의 선택도 함께 옮기며, 조건부 질문과 자동 계산은 유지됩니다. 기본 선택지 자체는 삭제할 수 없습니다.
저장값과 개별 CSV 칼럼명은 각각 사용자가 직접 편집합니다. **양식 적용 및 저장 → CSV 다시 내보내기**를 하면 기존 사고 전체에 변경 사항을 반영하며 사고별 재입력이 필요하지 않습니다. 저장값이 중복되거나 다른 선택지의 이전 저장값과 겹치면 적용을 막습니다. 현재 양식은 버전 5이며, 구버전 앱은 읽을 수 없습니다.
장애물(보행자)과 충돌 대상의 기본 선택지는 기존 ‘어른’을 유지합니다. 기본 저장값은 각각 `어른`, `pedestrian.adult`이며, 기본 개별 CSV 칼럼은 `obstacle_adult`입니다. 이전 수정본이 ‘어른, 청소년’과 `obstacle_adult,youth`로 자동 변경해 저장한 기본 양식도 열 때 복구하며 기존 선택을 유지합니다. 현재 버전에서 사용자가 직접 편집해 저장한 값은 재실행해도 유지합니다.
기존 JSON의 `schema_version: 1`·`2`를 모두 읽어 이전합니다. 새 SQLite DB에는 저장소 버전과 양식 버전을 별도로 보관합니다. JSON 전용 구버전 앱에서는 새 DB를 읽을 수 없습니다.

작업 폴더의 `investigations.db`에 사고별 조사 값, 표시 순서, 영상 경로, 영상별 타임라인 마커·회전 각도(0°/90°/180°/270°), draft/completed 상태를 저장합니다. 원본 영상은 DB에 복사하지 않습니다. 입력/마커 변경 시 해당 목록 행만 갱신하고, 저장 시 변경한 사고만 트랜잭션으로 반영합니다. 조사 양식 변경은 호환성 검증 때문에 전체 사고를 확인합니다.

기존 `investigations.json`이 있으면 첫 열기에서 임시 DB로 변환하고 무결성·내용을 검증한 뒤 활성화합니다. 원본 JSON은 수정·삭제하지 않으며 이후 저장은 DB에만 반영합니다. 이전 실패 시 원본을 보존하고 오류를 표시합니다. DB가 이미 존재하면 JSON보다 우선하며, DB 오류 시 오래된 JSON으로 자동 되돌아가지 않습니다. 구버전 앱으로 같은 폴더를 계속 편집하면 JSON과 DB 내용이 달라지므로 함께 사용하지 마세요.

저장·불러오기·CSV 내보내기·백업의 디스크 작업은 별도 스레드에서 순차 처리합니다. 임시저장 중 조사 입력은 계속할 수 있으며, 저장 요청 이후의 추가 수정은 미저장으로 남겨 다음 저장에 반영합니다. 완료는 검증과 저장이 모두 성공한 후 화면에 반영하며 실패 시 미완료 상태를 유지합니다.

**파일 → 조사 데이터 백업…**으로 실행 중에도 일관된 단일 `.db` 백업을 만들 수 있습니다. 복원하려면 앱을 닫고 백업을 새 로컬 폴더에 `investigations.db`라는 이름으로 복사한 뒤 그 폴더를 엽니다. 영상 경로는 별도로 유지해야 합니다. 실행 중 생길 수 있는 `-wal`·`-shm` 파일은 임의 삭제하지 말고, DB 파일만 탐색기에서 복사하는 대신 앱의 백업 메뉴를 사용하세요. 작업 DB는 로컬 디스크에서 단독 사용하며 NAS/동기화 폴더에서의 공동 편집은 지원하지 않습니다.

성능·오류 진단 로그는 기본 `%LOCALAPPDATA%/AVAT/logs`의 `avat.log`와 `crash.log`에 남습니다. 작업 시간·건수·프로세스 메모리와 오류 발생 위치를 기록하며 조사 입력값은 기록하지 않습니다. 로그는 크기 제한과 회전을 적용합니다. 강제 종료의 원인은 로그로 별도 확인해야 하며 모든 종료 상황에서 로그 기록이 보장되지는 않습니다.

다음 조건을 모두 만족해야 완료할 수 있습니다.

- 고정 식별 정보와 일반 필수 질문 입력
- 장소는 일반장소·특수장소·기타 텍스트 중 하나 이상 입력
- 장애물 `유`이면 객체 종류와 거동 상태 입력, 차량 장애물이 있으면 대면 상태 입력
- 피해 `확인 가능`이면 경상·중상·사망·물피 수치를 모두 입력 (`0`도 유효)
- 경상부상급수(12~14급)와 중상부상급수(1~11급)를 각각 쉼표로 입력하면 목록을 오름차순 정렬하고 해당 인원수를 자동 집계하며, 각 목록의 가장 낮은 급수를 경상·중상대표부상급수로 분리해 표시
- 날짜와 시간의 실제 형식 및 날짜-요일 일치
- 각 영상에서 트리거가 충돌 프레임보다 늦지 않음

완료한 사고를 다시 수정하면 안전을 위해 draft 상태로 돌아갑니다.

### 배포본에서 JSON 자동 이전 기능 제거

이전 완료 후 자동 이전 코드를 제외하려면 다음 두 단계만 수행합니다.

1. `investigator/storage.py`의 `_migrate_legacy()` 안에서 `from investigator.legacy_migration import migrate_legacy as migrator` 한 줄을 주석 처리합니다.
2. `investigator/legacy_migration.py` 파일을 삭제합니다.

나머지 저장소 함수는 유지합니다. 기존 DB 읽기·저장·백업 및 빈 폴더의 새 DB 생성은 정상 작동합니다. JSON만 있는 폴더는 이전 필요 안내와 함께 열기·저장·백업을 중단하여 기존 자료를 보호합니다. 기본 소스에서는 자동 이전이 활성화되어 있습니다.

## CSV 규칙

CSV 저장 위치를 선택하면 **데이터 명세서(94개 항목)도 함께 내보내기** 체크박스가 표시됩니다. 기본값은 선택이며, 해제하면 CSV만 저장합니다. 선택 시 기본 열 이름 변경을 반영한 명세서를 같은 폴더의 `<CSV 파일명>_데이터명세서.xlsx`로 저장합니다. 명세서는 기본 94개 열을 설명하며, 사용자 정의 양식으로 추가한 열은 포함하지 않습니다. 같은 이름의 명세서가 있으면 옵션 창에서 덮어쓰기를 안내합니다.

- 요청서에 적힌 칼럼명은 오탈자와 대소문자까지 그대로 유지합니다. 예: `vehicle_milege`, `obstacle_Existence`, `incident_damage_Unknown`, `Lighting/Environmental_Condition`.
- 화면에서는 사고일자를 먼저 표시하지만 CSV 칼럼 순서는 기존 계약인 `incident_day`, `incident_date`를 유지합니다.
- 옵션별 boolean 칼럼은 선택된 값만 `1`로 기록하고, 미선택·미입력·비적용 값은 `null`로 기록합니다. 사용자가 명시적으로 입력하거나 선택한 실제 값 `0`은 유지합니다.
- 한 칼럼에 들어가는 다중 선택은 스키마 순서대로 `|`로 연결합니다.
- `collision_target`은 요청서의 선택값 그대로 `승용|어른`처럼 내보냅니다.
- `active_video_file`, `trigger_frame`, `collision_frames`는 현재 선택 영상 기준이며, 모든 영상의 마커는 `video_markers` JSON에도 함께 보존합니다. 호환성을 위해 `collision_frames` 이름은 유지하지만 영상별 값은 최대 1개이며, 기존 다중 값은 가장 이른 충돌 시점 하나로 정규화합니다.
- 영상이나 마커가 지정되지 않은 워크플로 메타데이터 셀도 `null`로 기록하며, 실제 값 `0`은 그대로 보존합니다.
- 자유 텍스트가 스프레드시트 수식 문자로 시작하면 작은따옴표를 붙여 수식 실행을 방지합니다.
- 비고 탭의 사고 추가정보는 `remarks` 칼럼에 줄바꿈을 포함한 텍스트로 기록합니다.
- 요청서가 “기존 `site_*` 칼럼”의 정확한 이름을 제공하지 않아, 현 버전은 [CSV 스키마 문서](docs/CSV_SCHEMA.md)에 적힌 중앙 매핑을 사용합니다. 실제 기존 데이터셋 헤더가 제공되면 `investigator/schema.py`의 `SITE_CHOICES`만 교체하면 됩니다.
